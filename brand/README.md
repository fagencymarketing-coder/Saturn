# brand — официальный логобук «Сатурн» в токенах

Источник правды по бренду (оцифрован из логобука, Москва 2024). Использовать в
Claude Design, при сборке на Tilda и при доработке прототипа.

| Файл | Что это |
|---|---|
| `tokens.json` | Машиночитаемые дизайн-токены (цвета/типографика/отступы/радиусы/кнопки) |
| `variables.css` | CSS-переменные + готовые классы (btn, label) — вставлять в проект |
| `design-guide.md` | Дизайн-гайд текстом (таблицы, шпаргалка для Тильды) |
| `saturn-design-guide.html` | Визуальный гайд (открыть в браузере) |

## Ядро (из логобука — НЕ менять)
- **Saturn Orange `#FF4200`** — акцент: кнопки, ссылки, знак, активные состояния
- **Ink Black `#000000`** — логотип, заголовки, тёмный фон
- **White `#FFFFFF`** — основной фон
- Шрифт: **Gotham Pro** (печать) → веб-замена **Montserrat** (Google Fonts)
- Фирменный паттерн — полукруги (геометрия окружностей знака)

## Под веб (можно калибровать)
Состояния оранжевого (#E63B00 hover / #C43200 active / #FFF0EA tint), нейтрали
(#1A1A1A текст, #6B6560 вторичный, #F6F5F3 поверхность, #E7E3DE границы),
шкала типографики (H1 56 / H2 40 / H3 28 / body 17, вес 800/700/600/400),
сетка 8pt, радиусы (кнопки/поля 12px, карточки 20px, теги pill), кнопки
(высота 52px, паддинг 16×32, радиус 12px, вес 600).

## ⚠️ Расхождение с текущим прототипом (V4.4)
Прототип собирался ДО получения логобука и использует другие значения:
- оранжевый `#EE4A0E` (в логобуке `#FF4200`), тёмная коричнево-графитовая база,
  шрифты Archivo / IBM Plex, зелёный как вторичный акцент.
Логобук — источник правды. При доработке дизайна прототип нужно привести к этим
токенам (оранжевый #FF4200, Montserrat, светлая база + чёрный/оранжевый,
паттерн-полукруги). Тёмный герой допустим на Ink Black `#000000` + оранжевый.
