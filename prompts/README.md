# Промты агенту

Цепочка на один прогон без участия человека. Дарья вставляет агенту
в Chrome **только первый файл** — дальше агент сам открывает следующий.

| Файл | Что делает | Время |
|---|---|---|
| `PRAVILA.md` | общие правила, агент читает их сам | — |
| `AGENT-1-KATALOG.md` | каталог ST340F, английские надписи | 40 мин |
| `AGENT-2-NASTROYKI.md` | иконка сайта, превью ссылки, заглушка | 25 мин |
| `AGENT-3-BLOKI.md` | код в HEAD, шапка, подвал | 15 мин |
| `AGENT-3B-BLOKI-VERH.md` | первые четыре блока главной | 25 мин |
| `AGENT-3V-BLOKI-NIZ.md` | остальные блоки и публикация | 30 мин |
| `AGENT-4-PROVERKA.md` | проверка руками по всем ширинам, отчёт | 90 мин |
| `AGENT-5-ZAPUSK.md` | **вручную.** Сайт на корень домена | 15 мин |
| `AGENT-6-DODELKI.md` | доделки после прогона 03.10 | 40 мин |
| `AGENT-7-DOGON.md` | догон: код HEAD и девять блоков главной | 40 мин |
| `AGENT-8-SZR.md` | **вручную.** Раздел «СЗР» в магазине | 30 мин |

## Почему так мелко

03.10 прогон встал: за два с половиной часа на сайте не изменилось
ни байта. Это второй случай подряд. Первый промт тогда был один на
двадцать действий, второй — на двенадцать замен кода.

Поэтому ни в одном файле теперь не больше пяти действий, а замена
блоков разбита на три части. И каждый промт **безопасен к перезапуску**:
замена кода на тот же код ничего не меняет, так что цепочку можно
начать заново с любого места, не разбираясь, где именно агент встал.

## Если прогон опять встал

Понять это можно не спрашивая агента:

```
cd /home/user/saturn && bash tools/audit/priemka.sh
```

Если `live-blocks.py` говорит «не выложено» и размер страницы в байтах
тот же, что час назад, — агент стоит. Тогда вставить ему заново тот
промт, на котором он встал, или просто первый: повтор безвреден.

Промт 5 в цепочку не входит сознательно — он делает сайт видимым
снаружи, это решение человека.

## Чего агент не может

Прогон 03.10 упёрся в это, и упрётся снова: **публиковать страницы
агент не может.** Нажатие «Опубликовать» отклоняется ограничением его
среды (`Permission denied by the auto mode classifier`, причина
`[Production Deploy]`). То же самое с сохранением в окне «Настройки
страницы» (`[Unrequested Commit in a Connected App]`).

То же самое выяснилось 03.10 с магазином: создание раздела отклоняется
с причиной `[Modify Shared Resources]`. Поэтому промт 8 — инструкция для
рук, а не задание агенту.

Поэтому промты 1–4, 6 и 7 только готовят правки в Тильде, а публикует
их Дарья руками. Это не чинится формулировкой промта.
