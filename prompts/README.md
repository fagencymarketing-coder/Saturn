# Промты агенту

Цепочка на один прогон без участия человека. Дарья вставляет агенту
в Chrome **только первый файл** — дальше агент сам открывает следующий.

| Файл | Что делает | Время |
|---|---|---|
| `PRAVILA.md` | общие правила, агент читает их сам | — |
| `AGENT-1-KATALOG.md` | каталог ST340F, английские надписи | 40 мин |
| `AGENT-2-NASTROYKI.md` | иконка сайта, превью ссылки, заглушка | 25 мин |
| `AGENT-3-BLOKI.md` | код в HEAD, двенадцать блоков, публикация | 60 мин |
| `AGENT-4-PROVERKA.md` | проверка руками по всем ширинам, отчёт | 90 мин |
| `AGENT-5-ZAPUSK.md` | **вручную.** Сайт на корень домена | 15 мин |

Промты 1–4 идут цепочкой: в конце каждого ссылка на следующий.
Промт 5 в цепочку не входит сознательно — он делает сайт видимым
снаружи, это решение человека.

Почему порядок такой: каталог и настройки не зависят от блоков, а
блоки могут обновиться в репозитории прямо во время прогона. Поэтому
замена блоков стоит третьей, а не первой.
