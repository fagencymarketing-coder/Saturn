# Промт 22. Один шаг: код HEAD

Вопросов не задавать. Публиковать ничего не нужно — страницы опубликует
заказчица сама. Остальные блоки она вставляет руками, их не трогай.

Проект в Тильде `34592909`, сайт `sssaturn.ru` (ООО «Сатурн», Барнаул).

## Что сделать

Открыть редактор кода HEAD:
`https://tilda.cc/projects/editheadcode/?projectid=34592909`

Заменить содержимое поля **целиком** на этот файл:
https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/claude/nifty-fermat-az604f/design/blocks/head-code.html

Было **47 728** символов, станет **47 663**. Да, короче — из кода снято
одно правило (плавная прокрутка, из-за неё не доезжали якоря).

## Как проверить

Нажать «Сохранить» → выдержать паузу → **полностью перезагрузить
страницу редактора** → открыть поле заново → сверить длину.
Должно быть 47 663. Не сошлось — вставить заново и проверить снова.

В прошлые заходы это поле один раз легло только с третьего раза:
Тильда показывает зелёное «The code has been saved successfully», а
после перезагрузки в поле лежит старое. Не верь зелёной надписи,
верь длине после перезагрузки.

## Чего не делать

- Ничего не публиковать.
- Другие блоки, шаблоны «Шапка» и «Подвал», магазин, товары,
  настройки проекта, форму — не трогать.
- Кнопку «Опубликовать все страницы» не нажимать.
