# Промт 3 из 4. Код шапки и блоки главной

Третий из четырёх промтов. Правила:
https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/prompts/PRAVILA.md

Это самый длинный промт: двенадцать замен кода. Делай по одной,
после каждой сохраняй. Если какая-то не вышла — записывай и иди дальше.

Ориентировочное время: 60 минут.

---

## 3.1 Код в HEAD

Настройки сайта → Ещё → «Вставка кода» → поле **HEAD**.
Удали всё, что там сейчас, и вставь целиком содержимое файла:

https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/design/blocks/head-code.html

Сохрани.

Проверка: запиши в отчёт, сколько символов получилось в поле.
Этот код подставляет шапку, подвал, полосу заявки и баннер cookie
на страницы товара — без него страницы товара остаются голыми.

## 3.2 Шапка

Страницы-шаблоны → «Шапка» → блок T123 → Контент → поле HTML.
Заменить целиком на:

https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/design/blocks/shapka.html

## 3.3 Подвал

Страницы-шаблоны → «Подвал» → блок T123 → заменить целиком на:

https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/design/blocks/podval.html

## 3.4 Блоки главной

Страница «Главная». В каждом блоке T123: Контент → поле HTML →
заменить содержимое целиком. **Порядок блоков на странице не менять.**

Блоки идут сверху вниз в этом порядке:

| № | Блок на странице | Чем заменить |
|---|---|---|
| 1 | Герой, первый экран | `geroy.html` |
| 2 | Популярные позиции | `populyarnye.html` |
| 3 | Семена | `semena.html` |
| 4 | Агросопровождение | `agro.html` |
| 5 | Результаты испытаний | `rezultaty.html` |
| 6 | География | `geografiya.html` |
| 7 | Документы и сертификаты | `dokumenty.html` |
| 8 | Контакты | `kontakty.html` |
| 9 | Форма заявки | **штатный блок формы Tilda, не трогать** |
| 9а | Блок под формой | `forma-fix.html` |

Ссылка собирается так — подставь имя файла в конец:

```
https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/design/blocks/
```

Например:
https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/design/blocks/geroy.html

**Важно про порядок.** Если на странице «Результаты испытаний» и
«География» стоят в другом порядке, чем в таблице, — ничего не
переставляй, просто запиши это в отчёт. Содержимое клади в тот блок,
которому оно по смыслу принадлежит, а не по номеру.

**Важно про блок 9.** Форма заявки обязана остаться штатным блоком
формы Tilda, иначе заявки никуда не уйдут. У блока должен быть
CSS-класс `uc-saturn-form` — на него завязано оформление из
`forma-fix.html`. Если класса нет — поставь его и запиши в отчёт.

Что изменилось в коде по сравнению с тем, что сейчас на сайте:
отступы секций уменьшены со 128 до 80 пикселей и так же ужаты отступы
внутри секций; шапка стала 72px; у контактов появились значки;
расширены зоны нажатия. Тексты и картинки не менялись.

## 3.5 Опубликовать

Опубликовать **по одной** страницы, именно эти и только эти:

1. Главная
2. Семена
3. Агросопровождение
4. Контакты
5. Политика обработки персональных данных
6. Согласие на обработку персональных данных

Каталог уже опубликован в промте 1. Заглушку и `Blank page`
**не публиковать**. Кнопку «Опубликовать все страницы» не нажимать.

Проверка после публикации: открой https://sssaturn.ru/home — страница
открывается, шапка и подвал на месте, горизонтальной прокрутки нет.
