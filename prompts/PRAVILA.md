# Правила на весь прогон — читать перед каждым промтом

1. **Дарьи нет 3–4 часа.** Вопросов не задавай, ответа не жди.
2. **Не застревай.** Два захода на шаг — и хватит. Не получилось —
   пиши в отчёт «не сделано» с причиной и иди дальше. Один
   непройденный шаг не отменяет остальные.
3. **Ничего не удаляй** сверх того, что прямо названо в шаге.
4. **«Опубликовать все страницы» не нажимать никогда.**
   Публиковать только страницы из явного списка.
5. **Настройки проекта не трогать:** домен, почта, платежи, тариф,
   подключение доменов, формы-получатели.
6. **Отчёт веди по ходу**, а не в конце: после каждого шага дописывай
   строку в таблицу. Если вкладка закроется — отчёт не пропадёт.
7. **Названия настроек в Тильде меняются.** Если поле называется не так,
   как здесь, — найди по смыслу и запиши в отчёт, как оно называется
   на самом деле. Это ценнее скриншота.
8. **Скриншоты — только там, где спорно.** Не прикладывай скриншот к
   каждому шагу.
9. Код для вставки бери **по ссылке raw**, целиком, не переписывай руками
   и не правь на ходу.

## Формат отчёта

| Шаг | Статус | Что именно |
|---|---|---|
| 1.1 | сделано | — |
| 1.2 | сделано иначе | настройка называется «…», поставил … |
| 1.3 | не сделано | поля нет в интерфейсе |

Статус только один из трёх: `сделано`, `сделано иначе`, `не сделано`.
Числовые подтверждения обязательны там, где они есть: сколько товаров
нашлось, какой код ответа, сколько символов в поле.
