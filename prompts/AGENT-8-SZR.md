# Промт 8. Раздел «СЗР» в магазине

Правила:
https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/prompts/PRAVILA.md

Чип «СЗР» на главной должен открывать каталог, где видны **только средства
защиты растений**. Сейчас такого раздела в магазине нет: СЗР разложены
по пяти разделам. Одним адресом это не чинится — проверено, Тильда берёт
из адреса ровно один раздел, перечисление через `;`, `:::` и повтором
параметра не работает. Значит, раздел надо завести.

Ориентировочное время: 30 минут.

**Перезапуск безопасен:** если раздел «СЗР» уже есть и в нём 35 товаров —
ничего не делай, просто пришли его ID.

---

## 8.1 Создать раздел

«Магазин → Товары → Разделы» → добавить раздел с названием ровно:

```
СЗР
```

Верхнего уровня, не вложенный. Порядок в списке — после «Удобрения
и листовые подкормки», до «Адъюванты». Если переставить нельзя — оставь
где создалось и напиши в отчёт.

## 8.2 Добавить в него товары

Товары **остаются** в своих нынешних разделах — «СЗР» добавляется вторым,
а не вместо. Товар в Тильде может лежать в нескольких разделах сразу: так
уже сделано у семян, они одновременно в «Семена» и в «Гибриды».

По очереди для каждого из пяти разделов: открыть раздел → выделить все
товары → массовое действие **«Добавить в раздел»** (не «Переместить»!) →
выбрать «СЗР».

| Раздел | Товаров должно выделиться |
|---|---|
| Гербициды | 19 |
| Фунгициды | 3 |
| Инсектициды | 4 |
| Десиканты | 2 |
| Обработка семян и протравители | 7 |

Сумма 35, и это же число уникальных товаров — пересечений между
разделами нет, я проверил по магазину.

**Если массового действия «Добавить в раздел» нет**, а есть только
«Переместить» — не перемещай, товары пропадут из своих разделов.
Вместо этого открой товар и поставь галочку «СЗР» рядом с уже стоящей.
Это дольше, но безопасно. Напиши в отчёт, каким путём пошёл.

## 8.3 Проверить

Открой раздел «СЗР» в магазине: должно быть **35 товаров**. Проверь
выборочно три: в карточке товара разделов должно быть **два** — старый
и «СЗР».

Потом открой на сайте боковую панель каталога: пункт «СЗР» появился,
по клику показывает 35 карточек, первая — «Альфард, ВР».

## 8.4 Прислать ID раздела

Самое важное для меня. Нажми в каталоге на сайте пункт «СЗР» и скопируй
адрес из строки браузера целиком. Он будет такой:

```
https://sssaturn.ru/catalog?tfc_storepartnav[4384406801]=XXXXXXXXXXXX&tfc_div=:::
```

Нужны эти `XXXXXXXXXXXX` — двенадцать цифр. Без них я не могу привязать
чип.

---

## Чего не делать

- Не перемещать товары — только добавлять в раздел.
- Не переименовывать и не удалять существующие разделы.
- Не публиковать страницы. Изменения в магазине видны сразу, публикация
  для них не нужна.
- Не трогать цены, остатки, фото, артикулы.

## Отчёт

Шаг · сделано или нет · сколько товаров получилось · **ID раздела «СЗР»**.
