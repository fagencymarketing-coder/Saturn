# Промт 2 из 4. Иконка сайта, превью ссылки, заглушка

Второй из четырёх промтов. Правила те же:
https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/prompts/PRAVILA.md

Настройки проекта — домен, почта, платежи, тариф — **не трогать**.
Здесь только иконка сайта, превью ссылки и имя страницы-заглушки.

**Перезапуск безопасен.** Если какой-то шаг уже сделан — он просто
окажется уже сделанным, пропусти его и иди дальше.

Ориентировочное время: 25 минут.

---

## 2.1 Скачать файлы

Скачай себе четыре файла по прямым ссылкам, они понадобятся дальше:

- https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/assets/web-launch/favicon.ico
- https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/assets/web-launch/favicon-32.png
- https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/assets/web-launch/favicon-192.png
- https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/assets/web-launch/og-image.jpg

Проверка: og-image.jpg должен быть 1200×630.

## 2.2 Иконка сайта

Настройки сайта → Ещё → «Иконка сайта (favicon)».
Загрузи `favicon.ico`. Если Тильда просит PNG — `favicon-32.png`.
Если просит отдельную иконку для Android — `favicon-192.png`.

Если иконка уже стоит — не меняй, запиши в отчёт «уже стояла».

## 2.3 Превью ссылки для главной

Страница «Главная» → Настройки страницы → раздел «Соцсети»
(в части версий интерфейса он называется «Бейджик» или
«Facebook и Twitter») → поле «Изображение».
Загрузи `og-image.jpg`.

Проверка: в поле появилась картинка 1200×630.
Запиши в отчёт, как раздел называется в интерфейсе на самом деле.

## 2.4 Превью ссылки для каталога

То же самое для страницы «Каталог»: тот же `og-image.jpg`.

## 2.5 Переименовать заглушку

В списке страниц найди страницу-заглушку, которая сейчас стоит на
корне сайта. Переименуй её в **`Заглушка — не публиковать`**.

Меняется только имя страницы в списке. Адрес страницы, её содержимое
и то, опубликована она или нет, **не трогай**.

## 2.6 Снимок списка страниц

Сделай один скриншот списка всех страниц проекта: видно имя каждой
страницы и её состояние (опубликована / черновик). Приложи к отчёту.
Это нужно, чтобы понять, что в проекте осталось лишнего.
