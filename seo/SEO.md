# Техническое SEO и индексация — sssaturn.ru

Подготовлено 2026-09-29. Сайт собирается на Tilda: часть требований Tilda
закрывает сама, часть настраивается руками, часть готова в этой папке.

## Что лежит в папке
| Файл | Куда |
|---|---|
| `jsonld-site.html` | Разметка организации и сайта (Organization + LocalBusiness + WebSite). Tilda → Настройки сайта → Ещё → «HTML-код для вставки внутрь head» |
| `jsonld-breadcrumbs-catalog.html` | Хлебные крошки страницы каталога. Настройки страницы каталога → Дополнительно → код в head |
| `jsonld-products.json` | Разметка Product + Offer для 112 товаров — **запасной вариант**, см. ниже |
| `meta-pages.csv` | Title / Description / H1 для страниц |
| `meta-products.csv` | SEO Title / Description для 112 карточек товаров |

## 1. Делает Tilda сама — проверить, что включено
- **HTTPS** — сертификат выпускается автоматически после привязки домена.
- **sitemap.xml и robots.txt** — генерируются сами, открыть `sssaturn.ru/sitemap.xml`.
- **Адаптивность** — после сборки мобильной версии.
- **Ленивая загрузка и WebP** — Настройки сайта → Ещё → «Оптимизация изображений».
- **Разметка товаров.** Tilda Store выводит микроразметку карточек товара.
  После импорта прогнать 2–3 карточки через валидатор (см. п. 5). Если Product
  не находится — вставить блок из `jsonld-products.json` в код карточки.

## 2. Настроить руками в Tilda
1. **Одно зеркало.** Главный адрес — `sssaturn.ru` без www; `www.sssaturn.ru`
   → 301 на него. Настройки сайта → Домен.
2. **Старый домен.** `relict-altay.ru` → 301 на `sssaturn.ru` (у регистратора).
3. **Адреса страниц:** `/` главная, `/catalog` каталог, `/privacy` политика.
   Товары — человекопонятные адреса по SKU из файла импорта
   (`/catalog/tproduct/…-kvs-akvilon`), а не только числовые ID.
4. **Title и Description** каждой страницы — из `meta-pages.csv`;
   у товаров — поля SEO в карточке товара, из `meta-products.csv`.
5. **Один H1 на странице.** На главной — заголовок героя, в каталоге — «Каталог»,
   в карточке — название товара. Заголовки секций — H2, подразделы — H3.
   В Tilda тег заголовка выбирается в настройках блока.
6. **Хлебные крошки** на карточке товара: Главная › Каталог › Раздел › Товар.
   И видимые (строка над названием), и в разметке.
7. **Alt у картинок** — в настройках каждого изображения. У товаров Tilda
   подставляет название товара — этого достаточно.
8. **Open Graph** — картинка для соцсетей и мессенджеров 1200×630,
   Настройки сайта → SEO. Иначе ссылка в WhatsApp придёт без превью.
9. **Favicon** — знак «Сатурна», Настройки сайта → Ещё.
10. **Страница 404** — Настройки сайта → Ещё → «Страница 404».

## 3. Поисковики — после публикации
- **Яндекс Вебмастер**: подтвердить сайт, отправить sitemap, указать регион
  «Барнаул», проверить «Индексирование» через 1–2 недели.
- **Google Search Console**: то же самое.
- **Яндекс Бизнес** (карточка организации на Картах): адрес, часы, телефон,
  сайт — даёт показ в выдаче по «удобрения Барнаул» и на карте. **Для
  регионального B2B это даёт больше, чем вся остальная оптимизация.**
- **Яндекс Метрика** с вебвизором и целями на отправку форм — Tilda подключает
  счётчик одним полем.

## 4. 🔴 Юридически обязательное — без этого запускать нельзя
Формы сайта собирают имя и телефон — это персональные данные по 152-ФЗ.
- **Страница «Политика обработки персональных данных»** (`/privacy`).
  Сейчас её нет, а ссылка «политикой обработки персональных данных» под
  формами ведёт в никуда. Текст готовит юрист заказчика или конструктор.
- **Согласие на обработку** — галочка под каждой формой, не отмеченная
  заранее, со ссылкой на политику. С сентября 2025 согласие оформляется
  отдельным документом, а не строкой в политике.
- **Уведомление Роскомнадзора** о начале обработки ПДн — подаёт заказчик.
- **Баннер о cookie** — если подключена Метрика.
Штрафы за формы без политики и согласия — от 30 до 150 тыс. ₽ для юрлица.

## 5. Проверка после запуска
- Микроразметка: https://webmaster.yandex.ru/tools/microtest/ и
  https://validator.schema.org/
- Скорость: https://pagespeed.web.dev/ — цель: мобильная версия от 70.
- Мобильность: Вебмастер → Инструменты → Проверка мобильных страниц.
- Индексация: `site:sssaturn.ru` в Яндексе через 2 недели.

## Что даст рост дальше
Техническая часть даёт правильную индексацию, но трафик приносят страницы под
запросы. Для «Сатурна» это в первую очередь **страницы программ по культурам**
(«Защита и питание рапса», «…подсолнечника») — их мы уже заложили в каталоге
фильтром. Отдельные тексты по 3–4 главным культурам — следующий шаг, когда
сайт проиндексируется.
