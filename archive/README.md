# archive — исторические материалы проекта

Сюда сложено всё уникальное из прежних рабочих папок (`final/`, `incoming/`,
`_extracted/`), чтобы **ничего не потерялось**, но не мешало в основной структуре.

| Папка | Что внутри |
|---|---|
| `final/` | Мокапы, PDF ранних прототипов (v2–v5), скрипты рендера, эксперименты с шапкой/волнами |
| `incoming/` | Первая передача проекта: исходные HTML-прототипы, варианты заглушки coming-soon |
| `_extracted/` | Распакованный архив проекта: HTML-прототипы v2–v5, светлые/тёмные варианты заглушки |

- `SKIPPED.txt` — 12 PNG-рендеров заглушки (по ~5 МБ) в архив не вошли: это
  скриншоты, которые пересоздаются из сохранённых рядом HTML за минуту.
- Переписка с заказчиком (`chat.md` / `chat.txt`) **намеренно исключена** —
  в ней был пароль от reg.ru. Файлы остаются только локально и в `.gitignore`.

**Это архив, не рабочая область.** Актуальная работа — в `docs/`, `design/`,
`prototype/`, `assets/`, `catalogs/`, `brand/`.
