# CLAUDE.md — контекст проекта для Claude Code

Это память проекта. Прочитай меня первым, затем `README.md` и `docs/`.
Продолжаем работу над сайтом компании **«Сатурн»** (Success System) — поставщик
**удобрений, СЗР и семян** для профессионального земледелия. Оптовая торговля, домен **sssaturn.ru**.
Сайт делаем на **Tilda**. Репозиторий — единое хранилище проекта (наработки + вся информация).

## С чего начать
1. Прочитай `README.md`, `docs/DECISIONS.md`, `docs/BRAND.md`, `docs/OPEN-QUESTIONS.md`, `docs/DOMAIN-DNS.md`.
2. Ассеты: `assets/logo/` (логотип), `assets/icons/` (иконки SVG/PNG), `coming-soon/` (заглушки), `prototype/` (схема сайта).
3. Иконки — векторные SVG, параметрические (цвет/размер меняются в коде).

## Где мы сейчас (статус)
- **Заглушка (coming-soon):** сделано много вариантов (тёмные/светлые, с паттерном/пшеницей/эмблемами/зелёными акцентами). **Финал не выбран.** После выбора — подставить реальные контакты и сделать кликабельной.
- **Прототип сайта:** блочная схема (главная + каталог + карточка) — на согласовании.
- **Логотип:** извлечён из брендбука → PNG (белый/цветной, прозрачный фон), вшит в макеты.
- **Иконки:** монолинейный набор + группа СЗР + стилевая эксплорация (A/B/C/D) + эмблемы. Стиль/цвет — на согласовании.
- **Домен:** идёт подключение. sssaturn.ru временно недоступен для привязки к Tilda (ошибка «домен используется в другом проекте»). Временно поднимаем сайт на **relict-altay.ru** (домен дистрибьютора). Подробности — в `docs/DOMAIN-DNS.md`.

## Ближайшие задачи
1. Освободить/найти привязку домена sssaturn.ru в Tilda (см. DOMAIN-DNS.md), затем перевести сайт с relict-altay.ru на sssaturn.ru.
2. Выбрать финальную заглушку → сделать рабочую (кликабельные контакты, форма → nilov@sssaturn.ru) → опубликовать.
3. Утвердить стиль/цвет иконок → довести полный набор → вставить в карточки направлений и фильтры каталога.
4. Наполнить прототип реальным контентом (справка о компании, регалии/СГР, каталог).

## Правила по проекту
- **Не удалять MX/TXT-записи** домена при настройке DNS — иначе сломается почта (nilov@sssaturn.ru).
- Бренд: оранжевый **#EE4A0E** (основной) + зелёный акцент **#1F9E57** (кнопки/детали, агротематика). Полная палитра — BRAND.md.
- Тон текстов: лаконично, по делу («рабочий инструмент без воды»).
- Заглушки — самодостаточные HTML (логотип вшит base64), открываются в браузере как есть.
- Тяжёлые бинарники (PNG) держим сжатыми; для крупных файлов — Git LFS.

## Чего Claude Code делать НЕ может
- Подключать домен, менять DNS, заходить в Tilda/Reg.ru — это делает человек. Claude Code помогает с файлами, кодом (HTML/SVG), документацией, коммитами.
