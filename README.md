# Сайт ООО «Сатурн» (sssaturn.ru)

B2B-сайт-каталог: оптовые поставки удобрений, СЗР и семян + сервис (подбор,
диагностика, поставка, хранение, агросопровождение). Собирается на Tilda.

## С чего начать
Прочитайте **`docs/HANDOFF.md`** — там полный контекст проекта, решения,
структура прототипа, что можно/нельзя публиковать и как продолжить работу.

## Актуальный прототип
- Готовый HTML: `prototype/site-prototype-v44.html` (открыть в браузере)
- PDF: `prototype/Saturn-prototype-v44.pdf`
- Правки вносим в `prototype/build_v44.py`, затем:
  ```
  cd prototype
  python3 build_v44.py && node render_v44.cjs
  ```

## Структура
- `prototype/` — прототип главной, билд-скрипты, заглушка
- `docs/` — документация (HANDOFF, COMPANY, DESIGN-BRIEF, CLIENT-REQUESTS, …)
- `assets/` — логотип и иконки
- `catalogs/` — товарный каталог (xlsx) и выгрузки прайсов
- `research/` — исходные материалы (справка, КП, письмо, анализ конкурентов)

## ⚠️ Важно
- Не публиковать неподтверждённые цифры и активы производителя — см. `docs/COMPANY.md`.
- Партнёр «Генезис» публично не показывается (идёт под Relict Organics).
- Переписка с заказчиком (с паролем reg.ru) в репозиторий НЕ включена.
