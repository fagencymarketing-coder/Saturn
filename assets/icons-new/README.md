# assets/icons-new — новый официальный набор иконок

Набор **Phosphor Icons** (viewBox 0 0 256 256, единый стиль). Заменяет старые
нарисованные иконки из `assets/icons/` (те НЕ используем).

Цвет зашит `fill="#000000"` — под бренд перекрашивать в `#FF4200` или заменить
на `fill="currentColor"`, чтобы задавать цвет через CSS.

Партии присылаются постепенно; ниже — первый набор + предполагаемое назначение
(уточняется).
