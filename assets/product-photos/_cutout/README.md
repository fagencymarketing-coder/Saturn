# _cutout — упаковки, вырезанные с фона

Генератор: `assets/product-photos/cutout.py`

```
python3 assets/product-photos/cutout.py "путь/к/фото.jpg" ...
```

## Что делает
1. Убирает фон **заливкой от краёв**, а не по цвету. Это принципиально:
   мешки «Фертика» сами белые, и простое «убрать белое» пробило бы их насквозь.
2. Обрезает по содержимому, вписывает в квадрат 1200×1200 с полем 8%.
3. Мелкие исходники увеличивает, но не более чем в 2,2 раза — дальше начинается мыло.
4. Сохраняет PNG с прозрачностью.

## Настройки
- `THRESH = 16` — допуск при заливке. Больше — фон убирается чище, но
  начинает съедать светлые упаковки. Меньше — вокруг предмета остаётся кайма.
- `FEATHER = 1.2` — смягчение края.

## Если фото вырезалось плохо
Признаки: доля непрозрачных пикселей (печатается при запуске) меньше 0.15
или больше 0.7 — скорее всего либо съело предмет, либо фон остался.
Такие файлы отправляем заказчику на ручную обрезку в стороннем редакторе.
