## Для сайта (Tilda): просмотр без скачивания
Решение заказчика — документы **увеличиваются по клику в лайтбоксе**, не скачиваются.
Поэтому на сайт идут **изображения**, а не PDF (PDF Tilda только скачивает).

- `previews/` — PNG первой страницы (для макета в Claude Design).
- `web/` — **все страницы документов в JPG** (dpi 170, до 1600px, q88) для Tilda:
  `sgr-strada-01..04` · `sgr-diforma-01..07` · `sgr-mono-01..05` ·
  `sgr-ekomak-01..02` · `sertifikat-dilera-fertika-01`.

Как собирать на Tilda: карточка документа = обложка (стр. 1) + лайтбокс-галерея
со всеми страницами этого документа (листание внутри окна). Скачивание не
подключаем. PDF-оригиналы остаются в репозитории на случай запроса.
