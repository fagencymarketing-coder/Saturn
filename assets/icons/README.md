# Иконки

Векторные (SVG) + превью (PNG). Параметрические: цвет/размер меняются в коде.

- saturn-icons             монолинейный базовый набор (направления, услуги, культуры)
- saturn-icons-szr         группа СЗР (защита + гербицид/фунгицид/инсектицид/протравитель)
- saturn-icons-all         всё монолинейное на одном листе
- saturn-icons-styles      эксплорация стилей: A плитка · B градиент · C дуоцвет · D слои
- saturn-emblems-gradient  эмблемы (эко-щиты) в стиле B, оранж.+зелёный
- saturn-ecoshield         реплика референса (серебро+зелёный)
