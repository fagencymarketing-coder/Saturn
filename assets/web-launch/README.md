# Файлы для запуска на Tilda

| Файл | Куда в Tilda |
|---|---|
| `favicon.ico`, `favicon-32.png` | Настройки сайта → Ещё → Иконка сайта (favicon) |
| `favicon-180.png` | Иконка для iPhone (если Tilda просит отдельно) |
| `favicon-192.png`, `favicon-512.png` | Иконки для Android / ярлыка на экране |
| `og-image.jpg` (1200×630) | Настройки каждой страницы → Соцсети → Изображение: превью ссылки в мессенджерах |

Тестовый импорт каталога — `catalogs/tilda-import-TEST-5.csv` (5 товаров: удобрение с фото и ценой,
гербицид без фото, сорт без цены, товар без фото и цены, товар с двухчастной ценой).
Сначала импортировать его, проверить карточки, удалить — потом полный `catalogs/tilda-import.csv`.
