# assets/catalog-images — фото товаров из каталогов партнёров

Извлечено из официальных PDF-каталогов (`source-files/`) для карточек товаров на
сайте. Имя файла: `p<страница>_x<xref>_<ширина>x<высота>.jpeg`.

- `fertika/` — упаковки Фертика (Leaf Power, NPK, ЭКО Калий, Сульфат калия и др.), 18 шт.
- `relict/`  — канистры Реликт М (B/Mo/S/Zn/Si), Реликт Р, линейка РУС (Альфа/Биогель), 19 шт.
  - `relict/_certs/` — сертификаты/свидетельства (для блока «Документы»), 5 шт.
- `volsky/`  — канистры Волски Биохим (Микроэл, Экомак, Страда, серия по элементам), 23 шт.

Это фото продукции, которую «Сатурн» поставляет — использовать в карточках
каталога. Фоновые фото (поля, культуры) из тех же каталогов не включены; при
необходимости переизвлекаются из `source-files/` (см. извлечение через pymupdf).
Права: продуктовые снимки принадлежат производителям — использовать в контексте
продажи их продукции.
