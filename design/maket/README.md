# Утверждённый макет — сохранённый визуал

`maket-mobile-tablet-1790775427-3883.png` — рендер опубликованного
артефакта Claude Design, версия **1790775427-3883**
(https://claude.ai/artifact/LJucqWDUM6R3EMYQXkihhk), снят 03.10.2026.
Это тот самый макет, с которого сняты замеры
`design/measurements/mobile-tablet.json`.

Холст 3178×8169: экраны телефона и планшета рядом, плюс попапы.
Макет — один холст, адаптива внутри него нет: ширина окна браузера
на рендер не влияет.

**Чего здесь нет: холста для ПК.** Замеры `desktop.json` сняты с другого
холста, и его ссылки у меня нет. Пока он не сохранён здесь, источник
правды по ПК — только цифры из `desktop.json`, а это, как показала
история с блоком «Агросопровождение», недостаточно: по цифрам не видно
ни цвета иконки, ни того, есть ли соединительная линия.

Пересобрать рендер:

```
node /tmp/blk/maket.js
```

Скрипт открывает сохранённый HTML артефакта и снимает полную страницу.
