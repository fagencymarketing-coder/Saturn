## Известные правки к макету (первый приоритет — «чужие данные»)
- Герой, строка доверия: «12 лет на рынке» (не подтверждено, ОГРН 2023), «38 регионов поставок» (реально 8), ИНН «7701234567» (реальный 2801274078). Заменить на настоящие / убрать; ИНН в героя не выносить (место в подвале).
- Иконка направления «Удобрения» = колба (перепутана с диагностикой) — подобрать корректную.
- Ряд карточек «Популярные позиции»: 3 оранжевые кнопки подряд — оранжевый звучит слишком часто; оставить один акцент.
