# design/geo-map — карта «География поставок» (точные позиции)

Тёмная карта России для блока «География поставок» (зебра-палитра, `#141210`).
Построена по **реальным границам регионов**: каждый из 10 регионов поставок
обведён контуром, пины стоят по **центрам самих регионов** (центроид полигона),
поэтому каждый пин попадает внутрь своего контура.

- `saturn-map-site.png` — **версия для сайта**: без заголовка и легенды (они в вёрстке), пропорция 1,965 — как у `geo-map-10-outline.png` в макете, на замену ему.
- `saturn-map-geo.png` — самостоятельная картинка с заголовком и легендой.
- `map_ref.svg` — векторный источник (контуры регионов + подсветка 10 регионов +
  пины + выноски + легенда).
- `build_map.py` — генератор SVG. Проекция Albers conic (`lat1=50, lat2=65,
  lon0=100, lat0=56`); долготы Чукотки за датой сдвигаются +360. Центроид —
  площадный (shoelace) по крупнейшему кольцу региона.
- `render_map.cjs` — SVG → PNG (Playwright/Chromium, deviceScaleFactor 2).
- `regions.geojson` — границы всех 83 субъектов РФ (codeforamerica/click_that_hood,
  admin-1). Из них подсвечиваются 10 регионов поставок.

## Телефон и планшет — `build_map_single.py` (v3, основная)
**Одна карта, одним блоком** — та же композиция, что на ПК: вся Россия,
10 подсвеченных регионов, подпись у каждого. Отличие только в раскладке подписей:
на узком экране они крупнее относительно карты и вынесены в свободное место —
южные над и под Кавказом, сибирские «веером» от кластера, нижний ряд под картой.

| Файл | Экран | Логическая ширина | PNG | Подписи |
|---|---|---|---|---|
| `saturn-map-mobile-v3.png` | телефон (< 640) | 358px (390 − 2×16) | 3× → 1074×807 | 11,5px |
| `saturn-map-tablet-v3.png` | планшет (640–1199) | 704px (768 − 2×32) | 2× → 1408×782 | 13px |

На телефоне карта кадрирована от Кубани до Амура (без Калининграда и края
Чукотки) — так она на 25% крупнее; края кадра плавно уходят в фон.
Раскладка подписей — словари `MOBILE` / `TABLET` (координаты px холста);
скрипт падает, если подпись вылезает за край. Проверено в вёрстке на 375px
и 768px: читается, горизонтального скролла нет.
Старые `build_map_mobile*.py` / `saturn-map-mobile*.png` — предыдущие попытки.

```
python3 build_map_single.py
/opt/node22/bin/node render_map.cjs map_mobile_v3.svg saturn-map-mobile-v3.png 3
/opt/node22/bin/node render_map.cjs map_tablet_v3.svg saturn-map-tablet-v3.png 2
```
Третий аргумент `render_map.cjs` — плотность пикселей (по умолчанию 2).

## Пересборка
```
cd design/geo-map
python3 build_map.py                              # → map_ref.svg
MAP_SITE=1 python3 build_map.py                   # → map_site.svg (без заголовка и легенды)
/opt/node22/bin/node render_map.cjs map_ref.svg saturn-map-geo.png
/opt/node22/bin/node render_map.cjs map_site.svg saturn-map-site.png
```
🔴 `render_map.cjs` встраивает Montserrat из `catalogs/_fonts` и падает, если
шрифт не загрузился. Раньше Chromium молча подставлял Arial — подписи регионов
на сайте были набраны не фирменным шрифтом.

После рендера `saturn-map-site.png` обрезается по контенту до пропорции 1,965
(скрипт обрезки — в истории коммита 29.09).

## Пины (центроиды регионов), % от рамки карты 1600×900
Барнаул — офис (белое кольцо), остальные — оранжевые `#FF4200`.

| Регион | x % | y % |
|---|---|---|
| Ростовская обл. | 11.8 | 57.8 |
| Краснодарский край | 8.5 | 59.2 |
| Ставропольский край | 10.5 | 63.9 |
| Омская обл. | 36.4 | 67.9 |
| Новосибирская обл. | 40.1 | 72.0 |
| Алтайский край · Барнаул (офис) | 41.1 | 78.5 |
| Красноярский край | 51.2 | 53.4 |
| Амурская обл. | 72.7 | 72.6 |

Проекция коническая, поэтому западные регионы закономерно «поднимаются»
вверх-влево — это правильно, не ошибка.

## Стиль (эталон тёмной секции)
Фон `#141210`, обычные регионы `#211C18` (границы `rgba(255,255,255,.07)`);
регионы поставок — заливка `#3A2A20`, контур `rgba(255,66,0,.55)`; пины региона —
`#FF4200` (r≈8) с мягким ореолом; офис — белое кольцо + белая точка; выноски
`rgba(255,255,255,.35)`. Подписи Montserrat. Один акцент — оранжевый.
