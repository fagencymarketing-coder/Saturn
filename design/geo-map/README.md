# design/geo-map — карта «География поставок» (точные позиции)

Тёмная карта России для блока «География поставок» (зебра-палитра, `#141210`).
Точки регионов расставлены **не на глаз**, а спроецированы реальной
картографической проекцией по настоящему контуру страны.

- `saturn-map-geo.png` — готовый рендер (для вставки/трассировки в Claude Design).
- `map_ref.svg` — векторный источник (контур + точки + подписи + легенда).
- `build_map.py` — генератор SVG (проекция Albers conic, `lat1=50, lat2=65,
  lon0=100, lat0=56`; долготы Чукотки за датой сдвигаются +360).
- `render_map.cjs` — SVG → PNG (Playwright/Chromium, deviceScaleFactor 2).
- `RUS.geo.json` — контур России (johan/world.geo.json).

## Пересборка
```
cd design/geo-map
python3 build_map.py            # → map_ref.svg
/opt/node22/bin/node render_map.cjs   # → saturn-map-geo.png
```

западные регионы закономерно «поднимаются» вверх-влево (это правильно, не ошибка).

## Стиль (эталон тёмной секции)
Фон `#141210`, суша `#26211C`, границы `rgba(255,255,255,.16)`; точки региона —
`#FF4200` (r≈8) с мягким ореолом; офис — белое кольцо + белая точка. Подписи
Montserrat, белые/светло-серые. Один акцент — оранжевые точки.
