# Замеры макета

`desktop.json` и `mobile-tablet.json` — полный дамп утверждённого макета:
координаты, размеры, кегли, насыщенности, интерлиньяж, трекинг, цвета,
скругления, отступы, промежутки и ссылки у каждого элемента каждой секции.
Ширины: 1440, 768, 390.

**Нумерация секций на ПК и на узких ширинах разная на единицу**: на ПК полоса
цифр входит в герой, а на телефоне и планшете она отдельной секцией.

| Секция | ПК 1440 | 768 и 390 |
|---|---|---|
| Шапка | 0 | 0 |
| Герой | 1 | 1 |
| Полоса цифр | внутри героя | 2 |
| Популярные позиции | 2 | 3 |
| Семена | 3 | 4 |
| Агросопровождение | 4 | 5 |
| Результаты испытаний | 5 | 6 |
| География | 6 | 7 |
| Документы | 7 | 8 |
| Контакты | 8 | 9 |
| Подвал | 9 | 10 |
| Попап заявки (скрыт) | 10 | — |

## Как смотреть

```
python3 show.py 0          # шапка на всех ширинах
python3 show.py 10 390     # подвал только на 390 (на ПК подвал — секция 9)
python3 show.py 9 1440 3   # контакты на ПК, глубина вложенности до 3
```

## Как пересобрать

Дамп снят скриптом `dump.cjs` из рабочей папки сессии с опубликованного
макета Claude Design. Если макет изменится — пересобрать замеры заново,
иначе спецификации блоков разойдутся с дизайном.
