Самодостаточный промт. Всё по ссылкам.

## Проект

Сайт sssaturn.ru на Tilda, ООО «Сатурн». Главная — `/home`.

## Правила

1. Код брать по ссылкам целиком, как есть.
2. **Сверять не только длину, но и первую строку файла** — GitHub отдаёт
   raw с задержкой до пяти минут. Если первая строка не совпала с той,
   что указана ниже, скачай через GitHub API, а не по raw-ссылке.
3. После вставки сверять число символов.
4. Публиковать по одной странице.
5. Не нашёл блок — не правь соседний, напиши и остановись.
6. Если Tilda ответит «присутствует незакрытый тег» — не повторяй вставку,
   сообщи: это ошибка в файле, её чиню я.
