# Агенту — публикация всех правок sssaturn.ru (самодостаточно)

Ты вносишь правки в сайт на Tilda. Историю не помнишь — здесь всё, что нужно.
Все исходники берёшь по ссылкам из репозитория (в чат ничего не присылают).

## Правила (всегда)
1. Работай по одной странице/блоку. Перед сохранением сверяй длину (число знаков).
2. **«Опубликовать всё» НЕ нажимать.** Публикуй только названные страницы, по одной.
3. Не трогать: домен, DNS, почту, товары Магазина, блоки, которые не названы.
4. Если публикация блокируется средой — не обходи, напиши «готово к публикации»,
   заказчица опубликует сама.
5. После каждого шага — короткий отчёт (что сделал, сошлась ли длина).
6. При сохранении HEAD Tilda сама меняет одну латинскую «o» на кириллическую в
   «tildacopy» — это норма, длина не меняется.

## ОБЯЗАТЕЛЬНАЯ ПРОВЕРКА на живом сайте (ПК и телефон)
**Семена (критично):**
- Главная, блок «Популярные»: в чипах **НЕТ «Семена»**; среди карточек **НЕТ семян**
  (нет «ц/га», нет фото поля/подсолнухов) — только препараты/удобрения. ПК и телефон.
- /catalog: в разделах/чипах **НЕТ «Семена»**. ПК и телефон.
- Семена остаются только на /semena.

**Остальное:**
- Каталог: «Цена по запросу» видна у карточек без цены; цены на одном уровне.
- Карточки и страница товара: в цене НЕТ «(рассрочка …)».
- Форма и попап: у согласия нет красного уголка, у телефона одна рамка; имя обязательно.
- Планшет: доступны «Контакты» (бургер).
- Результаты: протоколы раскрываются списком. Документы: сертификаты списком.
- Товар без фото (напр. «Вега Клей»): на открытой странице слева **бежевая заглушка
  с эмблемой**, справа текст — пустой одной колонки быть не должно.
- На телефоне hero-кнопка «Каталог» — высотой ≥44px (тач-зона).
- /semena: на карточках списка видна подпись «Цена по запросу».
- Форма: имя с запятой («Иванов, агроном») принимается (строгое правило снято).
  Если всё ещё отказ «Укажите имя» — правило у Tilda в настройках поля: тип поля
  «Имя» → «Текст», обязательным оставить. Напиши заказчице.

Если на телефоне «Семена» где-то всё ещё виден — пришли, в каком элементе
(тег + класс через инструменты разработчика), добавят точный селектор.

## Задача 10. Сделать попап заявки глобальным (чтобы работал на страницах товара)
Проблема: на странице товара-семени кнопка «Запросить цену» перекидывает на блок
контактов, а не открывает попап. Причина: после удаления дубля попапа оставшийся
попап `rec4481417201` (с обязательным «Имя») есть только на /home, а на страницах
товара/семян попапа нет — кнопка по коду уходит на `/home#contacts` (запасной путь,
чтобы не быть «мёртвой»).
→ Разместить попап `rec4481417201` в **Footer (подвал)** — он глобальный и доезжает
  до всех страниц (там же раньше стоял удалённый дубль). Проверить: на странице
  товара-семени (напр. «Новосёл CL») кнопка «Запросить цену» **открывает одно окно
  заявки** (с обязательным «Имя»), а не уводит на контакты. То же на странице
  препарата («Оставить заявку»).
  Опубликовать /semena, /catalog и шаблон страницы товара.
