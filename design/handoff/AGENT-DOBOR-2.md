# Агенту — правки сайта sssaturn.ru (самодостаточно)

Ты вносишь правки в сайт на Tilda. Историю не помнишь — здесь всё, что нужно.

## Правила (всегда)
1. Работай по одной странице. Перед сохранением блока/HEAD сверяй длину (число знаков).
2. **«Опубликовать всё» НЕ нажимать.** Публикуй только названные страницы, по одной.
3. Не трогать: домен, DNS, почту, чужие блоки, которые не названы.
4. Если публикация блокируется средой (Production Deploy) — не обходи, напиши
   «готово к публикации», заказчица опубликует сама.
5. После каждого шага — короткий отчёт (что сделал, сошлась ли длина).
6. При сохранении HEAD Tilda сама меняет одну латинскую «o» на кириллическую в слове
   «tildacopy» — это норма, длина от этого не меняется.
7. Файлы берёшь из репозитория по ссылкам ниже (ничего не присылают в чат).

## Задача 1. Заменить код в поле HEAD сайта
Файл (≈ 54 085 знаков):
https://raw.githubusercontent.com/fagencymarketing-coder/Saturn/main/design/blocks/head-code.html
Что внутри (для проверки, менять не надо): в каталоге у карточек без цены видно
«Цена по запросу», цены выровнены по низу; из цены убрано «(рассрочка …)» и в
карточках, и на странице товара (МКР/фасовка остаются); в форме и попапе у согласия
нет красного уголка, у телефона одна рамка; описание в карточках каталога темнее
(читаемее).
→ Вставить в поле HEAD, сохранить, сверить длину, **опубликовать /home и /catalog**.

## Проверка на живом сайте (ПК и телефон)
- Каталог ПК: «Цена по запросу» видна у карточек без цены, цены на одном уровне.
- Каталог ТЕЛЕФОН: в разделах/чипах каталога НЕТ «Семена».
- Карточки и страница товара: в цене НЕТ «(рассрочка …)».
- Форма /home и попап: у согласия нет красного уголка, у телефона одна рамка.
- **Если на телефоне «Семена» всё ещё виден** — пришли, в каком элементе
  (тег + класс через инструменты разработчика), добавят точный селектор.
