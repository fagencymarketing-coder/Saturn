# Протоколы: оригиналы с затиркой (решение 27.10)

Публикуем **оригиналы актов**, присланные заказчиком, с видимой затиркой.
Набранные заново копии (`protocols/build_protocols.py`) **на сайт не идут** —
скрипт оставлен только ради данных для блока «Результаты».

## Что закрыто
Название и адрес хозяйства (регион оставлен), ФИО и подписи со стороны
хозяйства, номер и дата договора, строка хозяйства в блоке ЭДО, печать хозяйства.

## Что НЕ закрыто
Культура, сорт, ООО НПП «Генезис», Relict Organics, Волски Биохим, препараты
и нормы, урожайность, экономика, А.Ц. Нилова, Боровиков В.С., печать «Сатурна».

## Как сделано
`redact.py` ставит плашки по рамкам слов из OCR (`ocr.py`, tesseract rus) —
страницы отсканированы с перекосом, по строке целиком плашка промахивается.
Цвет плашки тёмно-серый: затёртый участок **должен быть виден**, белая затирка
читается как подчистка документа. Результат — растр, текст под плашкой не
извлекается выделением.

Исходные сканы в репозиторий **не кладём** — в них открытые данные хозяйств.
Они лежат только в рабочей папке чата. Пересборка: положить сканы в `orig/`
рядом с `redact.py` и запустить `python3 redact.py`.
