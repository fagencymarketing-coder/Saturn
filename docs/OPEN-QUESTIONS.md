# Открытые вопросы / что прислать

## Для запуска заглушки (блокеры)
- [ ] Реальный телефон (сейчас в макетах заглушка +7 ___).
- [ ] Ссылки WhatsApp / Telegram.
- [ ] Подтвердить почту формы: nilov@sssaturn.ru.
- [ ] Выбрать финальный вариант заглушки (тёмный/светлый + фон).

## Дизайн
- [ ] Финальный стиль иконок (монолиния / A / B / C / D) и цвет (оранжевый / зелёный / двухцветный).
- [ ] Оранжевый как основной или уходим в нейтраль (по желанию).
- [ ] Нужна ли EN-версия (в брендбуке есть RU/EN логотип).

## Контент сайта
- [ ] Справка о компании (текст «о компании», география, цифры).
- [ ] Список контактов, адрес, реквизиты (ИНН/ОГРН).
- [ ] Логотипы дистрибьюторов (Реликт/Фертика/Волский).
- [ ] Сертификаты и СГР (сканы/фото) — для блока регалий и карточек.
- [ ] Референс-лист клиентов (для блока «Нам доверяют») — опционально.
- [ ] Кто пишет описания/нормы применения в карточках товара.
