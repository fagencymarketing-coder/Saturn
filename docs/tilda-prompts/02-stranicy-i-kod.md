## Задача 1. Микроразметка в head

Настройки сайта → Вставка кода → поле для кода внутрь `<head>`.

Вставь туда содержимое:
https://raw.githubusercontent.com/fagencymarketing-coder/Saturnphoto/main/files/jsonld-site.html

Если в поле уже что-то есть — не стирай, добавь новое ниже. Сохрани.

## Задача 2. Страница «Политика обработки персональных данных»

1. Создай новую страницу, название: `Политика обработки персональных данных`
2. Адрес страницы: `privacy`
3. Добавь блок **T123** (библиотека блоков → «Другое» → «HTML-код») и вставь в него
   содержимое:
   https://raw.githubusercontent.com/fagencymarketing-coder/Saturnphoto/main/files/privacy.html
4. Настройки страницы → SEO:
   - Заголовок (title): `Политика обработки персональных данных — Сатурн`
   - Описание (description): `Как ООО «Сатурн» обрабатывает и защищает персональные данные посетителей сайта sssaturn.ru.`
5. Опубликуй страницу.

## Задача 3. Страница «Согласие на обработку персональных данных»

То же самое:

1. Название: `Согласие на обработку персональных данных`
2. Адрес страницы: `consent`
3. Блок **T123** с содержимым:
   https://raw.githubusercontent.com/fagencymarketing-coder/Saturnphoto/main/files/consent.html
4. Настройки страницы → SEO:
   - Заголовок: `Согласие на обработку персональных данных — Сатурн`
   - Описание: `Условия согласия на обработку персональных данных при отправке заявки на сайте sssaturn.ru.`
5. Опубликуй страницу.

## Задача 4. Страница 404

1. Создай страницу, название: `404`, адрес: `404`
2. Содержимое — любой простой блок с заголовком и кнопками:
   - Заголовок: `Страница не найдена`
   - Текст под ним: `Такой страницы нет или она переехала. Вернитесь на главную или посмотрите каталог.`
   - Кнопка 1: `На главную`, ссылка `/`
   - Кнопка 2: `Каталог`, ссылка `/catalog`
3. Настройки страницы → SEO → заголовок: `Страница не найдена — Сатурн`
4. Опубликуй страницу.
5. Настройки сайта → Еще → «Страница ошибки 404» → выбери созданную страницу `404`. Сохрани.

Страницы `/catalog` пока не существует — ссылку всё равно поставь.

Если в одно поле нельзя вписать два адреса — создай два отдельных подключения
сервиса Email, по одному на адрес.
