# Промт для Claude в Chrome — правовые страницы, 404, микроразметка, формы

Формат многовкладочный: вкладки адресуются по роли, не по номеру.

---

Работай в Chrome. Задача затрагивает несколько вкладок.

## ВКЛАДКИ

| Роль | URL | Назначение |
|---|---|---|
| SETTINGS | `https://tilda.ru/projects/settings/?projectid=34592909` | настройки проекта: вставка кода, формы, страница 404 |
| PAGES | `https://tilda.ru/projects/?projectid=34592909` | список страниц проекта: создание страниц |
| EDITOR | открывается из PAGES по клику на страницу | редактор страницы: блоки и их содержимое |
| SOURCE | `https://raw.githubusercontent.com/fagencymarketing-coder/Saturnphoto/main/files/` | исходные тексты, по трём адресам ниже |

Адреса для SOURCE:
- микроразметка — `.../files/jsonld-site.html`
- политика — `.../files/privacy.html`
- согласие — `.../files/consent.html`

## ПОДГОТОВКА

Получи список вкладок сессии. Для каждой роли: если вкладка с нужным URL уже
открыта — используй её, иначе открой новую и перейди по адресу. Дальше
обращайся к вкладкам по роли.

Проект — сайт `sssaturn.ru` (поставщик удобрений, СЗР и семян). На домене сейчас
висит временная страница-заглушка «Скоро здесь будет новый сайт». Её не трогай.

## ПЕРЕНОС ТЕКСТОВ МЕЖДУ ВКЛАДКАМИ

Тексты политики и согласия — юридические документы. Переносить их можно только
копированием, дословно:

1. В SOURCE перейди по нужному адресу.
2. Выдели всё (Ctrl+A), скопируй (Ctrl+C).
3. В EDITOR вставь (Ctrl+V) целиком в поле блока.

Нельзя: пересказывать своими словами, сокращать, править формулировки,
переписывать по памяти, менять знаки препинания. Если текст вставился не
полностью — повтори копирование, не дописывай руками.

## ЗАДАЧА

### 1. Микроразметка

1. В SOURCE открой `.../files/jsonld-site.html`, выдели всё, скопируй.
2. В SETTINGS открой «Вставка кода» → поле для кода внутрь `<head>`.
3. Вставь скопированное. Если в поле уже что-то есть — не стирай, добавь ниже.
4. Сохрани.

### 2. Страница «Политика обработки персональных данных»

1. В PAGES создай новую страницу с названием `Политика обработки персональных данных`.
2. Открой её в EDITOR.
3. Добавь блок **T123** (библиотека блоков → «Другое» → «HTML-код»).
4. В SOURCE открой `.../files/privacy.html`, выдели всё, скопируй.
5. В EDITOR вставь скопированное в поле кода блока. Сохрани блок.
6. Настройки страницы:
   - Адрес страницы: `privacy`
   - Заголовок (title): `Политика обработки персональных данных — Сатурн`
   - Описание (description): `Как ООО «Сатурн» обрабатывает и защищает персональные данные посетителей сайта sssaturn.ru.`
7. Опубликуй страницу.

### 3. Страница «Согласие на обработку персональных данных»

То же самое:

1. В PAGES создай страницу `Согласие на обработку персональных данных`.
2. В EDITOR — блок **T123**.
3. Текст из SOURCE: `.../files/consent.html`, копированием.
4. Настройки страницы:
   - Адрес: `consent`
   - Заголовок: `Согласие на обработку персональных данных — Сатурн`
   - Описание: `Условия согласия на обработку персональных данных при отправке заявки на сайте sssaturn.ru.`
5. Опубликуй страницу.

### 4. Страница 404

1. В PAGES создай страницу `404`.
2. В EDITOR добавь простой блок с заголовком и двумя кнопками:
   - Заголовок: `Страница не найдена`
   - Текст: `Такой страницы нет или она переехала. Вернитесь на главную или посмотрите каталог.`
   - Кнопка 1: `На главную`, ссылка `/`
   - Кнопка 2: `Каталог`, ссылка `/catalog`
3. Настройки страницы: адрес `404`, заголовок `Страница не найдена — Сатурн`.
4. Опубликуй страницу.
5. В SETTINGS → «Еще» → «Страница ошибки 404» выбери созданную страницу. Сохрани.

Страницы `/catalog` пока не существует — ссылку всё равно поставь.

### 5. Приём заявок на почту

В SETTINGS → «Формы» подключи сервис **Email** с двумя адресами:

```
nilov@sssaturn.ru
slobodina.marina@sssaturn.ru
```

Если в одно подключение нельзя вписать два адреса — сделай два отдельных
подключения сервиса Email, по одному на адрес. Если Tilda требует подтверждения
адреса письмом — отправь запрос и напиши об этом в отчёте.

## ПРОВЕРКА

1. Перезагрузи SETTINGS и убедись, что микроразметка и страница 404 сохранились,
   а в «Формах» видны оба адреса.
2. Открой опубликованные страницы `https://sssaturn.ru/privacy` и
   `https://sssaturn.ru/consent` и проверь:
   - текст не обрезан, виден до последнего раздела;
   - в политике отображается таблица в разделе 3 (не «съехала» в сплошной текст);
   - ссылки внутри текста кликабельны;
   - на узком окне (сузь окно до ширины телефона) текст не вылезает за край.
3. Открой `https://sssaturn.ru/nesushchestvuyushchaya-stranica` и убедись, что
   показывается страница 404, а не пустая страница Tilda.

Скриншоты делай уже в сохранённом и опубликованном состоянии.

## ОГРАНИЧЕНИЯ

- Меняй только перечисленное, ничего больше не трогай.
- Ничего не удаляй.
- Публиковать разрешено **только** три страницы из задач 2, 3 и 4. Главную
  страницу, заглушку и сайт целиком не публикуй.
- Настройки шрифтов и цветов не трогай — они уже выставлены верно.
- Значения вставляй ровно как написано.
- Если блока, раздела или поля нет — пропусти и напиши об этом, не выдумывай
  обходной путь молча.
- Вкладки, которые открыл сам, закрой в конце. Вкладку SETTINGS оставь открытой.
