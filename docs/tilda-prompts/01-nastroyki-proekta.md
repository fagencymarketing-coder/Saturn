# Промт для Claude в Chrome — настройки проекта Tilda

Открыть вкладку с Tilda, проект 34592909, и отправить этот текст.

---

Ты работаешь в моей вкладке с Tilda, проект id 34592909 (сайт sssaturn.ru).
Заполни настройки проекта строго по списку ниже.

Правила:
- Меняй только то, что перечислено. Ничего больше не трогай.
- Ничего не удаляй и не публикуй.
- Не меняй настройки шрифтов — они уже выставлены верно.
- Значения вставляй ровно как написано, вместе со знаком #.
- Если поле уже заполнено другим значением — замени на моё.
- Если какого-то раздела или поля нет, пропусти его и напиши мне об этом в конце.
- После каждого раздела нажимай «Сохранить изменения».

## 1. Настройки сайта → Основное

- Название сайта: Сатурн
- Описание сайта: Поставщик удобрений, средств защиты растений и семян для профессионального земледелия
- Язык сайта: русский

## 2. Настройки сайта → Цвета и стили → блок «Цвета»

- Цвет заголовков: #141210
- Цвет текста: #141210
- Цвет ссылок: #FF4200
- Цвет фона страницы: #FFFFFF

Раскрой «Дополнительные настройки» и заполни:

- Толщина подчеркивания: 1px
- Цвет подчеркивания: #FF4200
- Цвет ссылок при наведении: #D93800
- Цвет подчеркивания при наведении: #D93800

## 3. Настройки сайта → Цвета и стили → «Управление стилями»

Нажми «Управление стилями», затем «Добавить цвет» и добавь девять цветов,
по одному, в этом порядке:

## 4. Настройки сайта → Ещё → предупреждение об использовании cookie

Включи баннер и заполни:

- Текст: Мы используем файлы cookie и Яндекс Метрику, чтобы сайт работал удобнее. Продолжая пользоваться сайтом, вы соглашаетесь с политикой обработки персональных данных.
- Ссылка: /privacy
- Текст ссылки: политикой обработки персональных данных
- Надпись на кнопке: Хорошо
- Положение: внизу экрана
- Показывать: один раз

Страницы /privacy пока не существует — это нормально, всё равно поставь эту ссылку.

## 5. Скриншоты — обязательно

Когда все четыре раздела заполнены и сохранены, пройди по ним заново и сделай
скриншот каждого экрана. Нужно шесть штук, в этом порядке:

1. Настройки сайта → Основное (видны название, описание, язык)
2. Цвета и стили → блок «Цвета» (видны все четыре поля с вписанными значениями)
3. Цвета и стили → раскрытые «Дополнительные настройки» (видны все четыре поля)
4. «Управление стилями» — список добавленных цветов, все девять в кадре
5. Настройки сайта → Ещё → предупреждение о cookie (виден текст, ссылка, кнопка)
6. Настройки сайта → Шрифты (видны Montserrat, насыщенность и размер)

Требования к скриншотам:
- Снимай уже сохранённое состояние, а не форму до нажатия «Сохранить».
- Значения в полях должны быть видны и читаемы, не обрезаны.
- Если список цветов не помещается в один кадр — сделай два и скажи об этом.
