# Ручная публикация правок (Дарья, в редакторе Tilda)

Агент не может править живой код автоматически (защита среды) — поэтому код
вставляешь сама, агент проверяет результат. Публикуешь по одной странице,
«Опубликовать всё» не нажимать. Все файлы — по raw-ссылкам из репозитория.

## Шаг 1. HEAD (главное)
Настройки сайта → Вставка кода → «HTML-код внутрь HEAD» → выделить всё, удалить,
вставить файл целиком. Счётчик ≈ **54 054**. Сохранить.
Файл: `…/Saturn/main/design/blocks/head-code.html`
Даёт: у товара без фото бежевая заглушка; «Цена по запросу» на карточках /semena;
рассрочка убрана; моб. ритм карточек. (Подмена «o»→кириллица в «tildacopy» — норма.)

## Шаг 2. Переставить попап заявки в Footer (чтобы «Запросить цену» у семян работало)
Попап `rec4481417201` (с обязательным «Имя») разместить в **Footer (подвал)** — он
глобальный, появится на всех страницах. Тогда на странице семени «Запросить цену»
откроет окно заявки, а не уведёт на контакты.

## Шаг 3. Обновить 3 блока (полировка — мелочи приёмки)
На странице /home заменить HTML в этих блоках, сверить длину, сохранить:
- Первый экран (герой): `…/design/blocks/geroy.html` — кнопка «Каталог» ≥44px.
- Форма: `…/design/blocks/forma-fix.html` — имя с запятой проходит.
- Результаты: `…/design/blocks/rezultaty.html` — кнопка «Все протоколы» как «Все документы».

## Шаг 4. Опубликовать (по одной)
`/home` · `/catalog` · `/semena` · шаблон **страницы товара** · `/privacy` · `/consent`.
(Шаблон товара — одна публикация обновит все карточки; нужен для заглушки у «Вега Клей».)

## Шаг 5. Проверка на живом (ПК + телефон 390px)
- Товар без фото («Вега Клей») — слева бежевая заглушка с эмблемой, не пусто.
- /semena: на карточках видна «Цена по запросу»; «Запросить цену» открывает окно.
- Каталог: «Цена по запросу» у позиций без цены; «(рассрочка …)» нет нигде.
- Герой на телефоне: кнопка «Каталог» не крошечная.
- Форма: имя с запятой проходит; у согласия нет красного уголка, у телефона одна рамка.
