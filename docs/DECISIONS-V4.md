# Решения по V4 (согласовано с заказчиком через дизайнера)

Дата: 2026-09-10. Основано на «Финальные рекомендации по сайту ООО «Сатурн»»
(final-brief.txt) + подтверждения дизайнера.

## Тип и цель сайта
Компактный B2B-сайт-каталог (НЕ интернет-магазин). Цель — знакомство с
ассортиментом + получение запроса. Центральная тема — комплексная модель:
подбор → диагностика → поставка → хранение → агросопровождение.

## Подтверждённые решения
1. **Дизайн:** тёмная коричнево-графитовая основа + оранжевый акцент, НО больше
   светлого тёплого фона; приглушённый зелёный — вторичный (фильтры, культуры,
   диагностика). Оранжевый — преимущественно для CTA и статусов.
2. **Партнёры:** оставляем как есть (Genesis НЕ выводим публично — идёт под
   Relict Organics). Без противоречащего числа «3 производителя».
3. **Цены:** «Базовая цена от…» + «Цена по запросу»; подпись «итоговая
   стоимость зависит от объёма, региона и условий поставки»; кнопка
   «Получить предложение» (не «Купить»).
4. **Этап 1:** главная + приоритетные карточки + разделы (диагностика,
   агросопровождение, география, партнёры, контакты). Полный каталог с
   фильтрами — Этап 2.
5. **С главной убрать** карточку с техническими характеристиками (демо-карточка
   товарной страницы).

## Структура главной (11 блоков)
1. Первый экран: H1 «Семена, удобрения и защита растений для
   сельхозпроизводителей» + подзаголовок + CTA «Подобрать решение» /
   «Перейти в каталог».
2. Пять направлений: Удобрения / СЗР / Семена / Диагностика / Агросопровождение.
3. Быстрый подбор по культуре или задаче.
4. Популярные позиции / линейки.
5. Сервис «под ключ»: подбор — диагностика — поставка — сопровождение.
6. География (8 регионов).
7. Производители и партнёры.
8. Испытания и результаты (кейсы).
9. Документы и сертификаты.
10. Специалисты и контакты.
11. Финальная форма запроса.

## Правки после разбора прототипа (V4.1)
Внесены по детальному ревью заказчика/дизайнера. Новая последовательность: 1 экран
→ направления → подбор → товары → сервис (4 этапа) → о компании → география →
производители → условия сотрудничества → испытания → документы → специалист →
форма → футер.
- **Подбор:** добавлено действие «Показать подходящие продукты» + «Спросить агронома».
- **Цены:** без противоречий. С ценой → «от 227 ₽/кг» + «Рассчитать поставку»;
  без цены → «Цена по запросу» + «Получить предложение». Подпись под каталогом.
- **Название:** «Фертика Листовое Старт 13-40-13» (не Fertika STARTER).
- **Цифры:** 15+/500+/1000+ убраны из макета совсем (остаются только проверяемые:
  8 регионов, 5 направлений, оптовые поставки, диагностика/агросопровождение).
- **Лаборатория:** формулировка смягчена — «Функциональная листовая диагностика»
  без слова «собственная», до юр. подтверждения. ⚠️ уточнить у заказчика.
- **Кейсы:** «до +15% на пшенице», «+4% на сое», нейтральные описания
  (без «схемы питания/защиты»), дисклеймер про условия. Имя «СибАгро» убрано до
  согласования.
- **Производители:** заголовок «Представляем продукцию российских производителей»
  + ссылки «Смотреть продукцию». 3 карточки (Фертика, Волски Биохим, Relict).
- **Новый блок «Условия сотрудничества»** (оптовые поставки, доставка, хранение,
  оплата) — для закупщика.
- **Новый блок «О компании»** (краткий) + пункт меню.
- **Диагностика и агросопровождение** разведены в два отдельных описания с
  разными кнопками; подробная 6-этапная цепочка диагностики — на отдельную
  страницу услуги (не на главной).
- **География:** «География поставок», легенда (офис/регионы/по запросу).
- **Форма на главной сокращена:** имя, телефон, регион, что требуется, комментарий.
  Полная форма (культура/площадь/объём) — на отдельной странице.
- **Специалисты:** Нилов — «коммерческий руководитель · основной контакт»;
  Хаблак — «специалист по поставкам · зона ответственности уточняется».
- **Меню:** Каталог · По культурам · Диагностика · Агросопровождение · О компании ·
  Контакты. География и производители — секции, не пункты меню 1-го уровня.
- **Кнопка «Подобрать решение»** — зелёная. Партнёры — 3. Реквизиты в подвале.
