# Сборка главной страницы

Главная собирается из блоков **T123 (HTML-код)**, по одному блоку на секцию.
Все файлы лежат в `design/blocks/`, забираются по прямой ссылке:

```
https://raw.githubusercontent.com/fagencymarketing-coder/saturn/main/design/blocks/<файл>
```

## Почему форма — не HTML

Форма обязана быть штатным блоком Tilda, иначе заявки никуда не уйдут:
Tilda принимает отправку только от своего обработчика. HTML-форма в T123
просто перезагрузит страницу и потеряет заявку.

Настройки блока формы:
- поля: `Имя` (text, name), `Телефон *` (phone, обязательное);
- галочка согласия — обязательная, по умолчанию снята;
- текст галочки: «Я даю согласие на обработку персональных данных и принимаю
  политику обработки персональных данных», ссылки на `/consent` и `/privacy`;
- сообщение после отправки: «Спасибо! Перезвоним в течение рабочего дня.»;
- получатели: `nilov@sssaturn.ru` и `slobodina.marina@sssaturn.ru`
  (Настройки сайта → Формы, обе почты должны подтвердить письмо от Tilda);
- **CSS-класс блока: `uc-saturn-form`** — на него завязан файл `forma-fix.html`.

## Что ещё не доделано

- **Ссылки карточек товаров.** В `populyarnye.html` и `semena.html` у карточек
  стоит `href="/catalog"` и атрибут `data-sku` с артикулом. Когда станут
  известны адреса страниц товаров в каталоге Tilda — заменить `href`
  на них. Артикулы: `fertika-listovoe-18-18-18`, `strada-n`,
  `ampir-ekstra-vr`, `chellendzher-vrk`, `kvs-akvilon`, `ampir-10-express`,
  `novosel-cl`, `ampir-25-express`.
- **Чипы разделов** в `populyarnye.html` тоже ведут на `/catalog` без раздела,
  нужный раздел записан в `data-section`.
- **Фото.** Исходники макета распакованы из артефакта в `assets/design-export/`
  и опубликованы. Карта географии на ПК — тот же файл, что на планшете
  (1408×762): отдельного десктопного рендера в макете не было.
