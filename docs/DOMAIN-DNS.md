# Домен и DNS — статус и инструкция

## Ситуация
- Основной домен проекта — **sssaturn.ru** (регистратор Reg.ru, аккаунт alexmillou85@gmail.com).
- При подключении sssaturn.ru к Tilda возникает ошибка **«домен используется в другом проекте»** — домен где-то уже привязан внутри Tilda (в другом проекте или другом аккаунте). Пока не найдено, где.
- **Временное решение:** сайт поднимаем на домене дистрибьютора **relict-altay.ru** (тоже в этом Reg.ru-аккаунте), чтобы не ждать. Позже переедем на sssaturn.ru.

## Как подключить домен Reg.ru → Tilda (рабочая схема)
1. В Tilda: проект → Настройки сайта → **Домен** → вписать домен → Сохранить → скопировать **IP**, который покажет Tilda (сейчас это **176.57.67.146**).
2. В Reg.ru: карточка домена → **DNS-серверы**: выбрать `ns1.reg.ru, ns2.reg.ru` (чтобы был доступен редактор записей).
3. В Reg.ru: **Ресурсные записи** → добавить две записи типа **A**:
   - `@`  → 176.57.67.146
   - `www` → 176.57.67.146
   - удалить старые A-записи с другим IP (например, был старый 89.221.206.103).
4. **MX и TXT не трогать** (почта!).
5. Подождать обновления DNS (15 мин — 24 ч), в Tilda жать **«Проверить»** пока не позеленеет.
6. Включить **SSL/HTTPS** в Tilda (бесплатно).

Проверка обновления DNS: dnschecker.org → домен, тип A → должен показать 176.57.67.146.

## Текущее состояние записей
- **relict-altay.ru** (Reg.ru): NS = ns1/ns2.reg.ru; A `@` и `www` → 176.57.67.146. Настроено верно, ждём обновления DNS/проверки в Tilda.
- **sssaturn.ru**: зону в Reg.ru пока не трогали для сайта; почта на домене настроена (MX). НЕ удалять MX.

## Как найти, где занят sssaturn.ru в Tilda
1. В своём аккаунте Tilda пройтись по ВСЕМ проектам → Настройки → Домен → искать sssaturn.ru (включая черновики/тестовые). Нашли — стереть, Сохранить.
2. Если нигде нет — домен занят в ДРУГОМ аккаунте Tilda. Написать в поддержку **support@tilda.cc**:
   > При подключении домена sssaturn.ru Tilda пишет «домен используется в другом проекте». В нашем аккаунте его нет. Домен наш (Reg.ru, подтвердим). Подскажите, в каком аккаунте занят, и помогите освободить.
3. Полезно вспомнить, кто раньше настраивал сайт/почту sssaturn.ru — вероятно, домен «застрял» в его аккаунте Tilda.

## Важно (частые ошибки)
- Почта (MX) и сайт (A) — независимы; настроенная почта НЕ мешает подключению сайта и наоборот. Ошибка Tilda — чисто внутренняя привязка домена к проекту, не про DNS.
- По IP-адресу НЕЛЬЗЯ узнать, в каком аккаунте Tilda занят домен — это не в DNS.
- Reg.ru не знает про проекты Tilda; освобождение домена решается только в Tilda / её поддержкой.
