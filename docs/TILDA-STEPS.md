# Как перенести сайт на Tilda — пошагово

Порядок важен: каждый следующий шаг опирается на предыдущий. Ориентировочно 2–3 рабочих дня.
Справочник по блокам — `TILDA-PLAN.md`, готовность — `TILDA-READY.md`.

## Шаг 0. Проверить домен — ✅ СДЕЛАНО (30.09.2026)

Домен уже на Tilda: A `@`/`www` → 176.57.66.96, SSL валиден, заглушки reg.ru нет,
почтовые записи (MX Яндекса, SPF, DKIM) на месте. Сейчас на домене висит временная
страница «Скоро здесь будет новый сайт». Подробности — `DOMAIN-DNS.md`.
Начинать сразу с шага 1.

**Заглушку не удалять, пока новый сайт не собран.** Новую главную собираем отдельной
страницей, а заглушку снимаем с адреса `/` в самый последний момент — на шаге 10,
когда всё проверено. Иначе посетители увидят полусобранный сайт.

<details><summary>Что проверялось, если домен вдруг отвалится</summary>

Открыть `sssaturn.ru` в браузере.

- Видно заглушку reg.ru «Домен привязан к хостингу» → в reg.ru: **Хостинги → сайт sssaturn.ru → открепить домен**.
  A‑записи `@` и `www` оставить только на IP, который показывает Tilda (Настройки сайта → Домен).
  **MX не трогать** — на них живёт почта.
- Видно пустую страницу Tilda → всё в порядке, идём дальше.
- В Tilda домен не зелёный → там же кнопка «Проверить», ждать до 24 ч, затем включить бесплатный SSL.

**MX, SPF и DKIM не трогать ни при каких настройках сайта** — на них держится почта
`@sssaturn.ru`, в том числе адреса, куда приходят заявки с форм.

## Шаг 1. Настройки проекта (40 минут)

Всё это делается один раз и действует на весь сайт. Заходим: проект → **Настройки сайта**.

### 1.1. Основное

- **Название сайта:** `Сатурн`
- **Описание сайта:** `Поставщик удобрений, средств защиты растений и семян для профессионального земледелия`
- **Язык сайта:** русский
- **Favicon:** загрузить `assets/web-launch/favicon.ico`

Название и описание — это запасные значения. У каждой страницы будут свои Title
и Description из `seo/meta-pages.csv`, они главнее.

### 1.2. Шрифты и цвета → шрифты

Вкладка **Google Fonts** (не «Библиотека»), шрифт **Montserrat**, отметить начертания:
**400, 500, 600, 700, 800**. Больше ничего не отмечать — каждое начертание это
отдельный файл и лишний вес страницы.

Почему Google Fonts, а не «Библиотека»: в библиотеке Tilda подгружает не все
начертания, и заголовка 800 может не оказаться. Тогда там, где в макете ExtraBold,
молча отрисуется Bold, и главная станет легче макета.

Ниже на той же странице:

| Настройка | Ставим | Почему |
|---|---|---|
| Шрифт заголовков | Montserrat | |
| Шрифт текста | Montserrat | |
| Насыщенность текста | **Normal** | в списке Tilda только Light и Normal; Normal — это и есть 400 из макета |
| Размер текста | **18px** | минимум, который даёт Tilda (18/20/22/24). Влияет только на стандартные блоки — правовые страницы и описания товаров; в Zero Block размер задаётся у каждого элемента и эту настройку перебивает |
| Насыщенность заголовков | **Bold** | в макете заголовки секций 800, крупные 700; Semibold заметно легче, а весь стиль держится на контрасте тонкого текста и плотного заголовка |
| Показывать системный шрифт при загрузке | **включить** | без этого на медленном мобильном интернете посетитель видит пустой экран, пока грузится шрифт |

### 1.3. Шрифты и цвета → цвета проекта

Сохранить палитру, чтобы она была в каждом выпадающем выборе цвета и не набирать
коды руками в каждом блоке. Цвета проверены по макету:

| Код | Где применяется |
|---|---|
| `#FF4200` | акцент: кнопки, активные чипы, подчёркивания |
| `#141210` | основной текст и тёмные секции |
| `#FFFFFF` | текст на тёмном, карточки |
| `#F6F5F3` | фон светлых секций |
| `#F0EDE9` | плитки и карточки внутри светлых секций |
| `#EDE9E4` | линии‑разделители на светлом |
| `#8A837C` | подписи и второстепенный текст на светлом |
| `#B5B0AA` | второстепенный текст на тёмном |
| `#1E1B18` | карточка формы на тёмном фоне |

Основной цвет ссылок — `#FF4200`, основной цвет текста — `#141210`, фон сайта — `#FFFFFF`.

### 1.4. Ещё → HTML-код внутрь head

Вставить содержимое `seo/jsonld-site.html` — микроразметка организации для Яндекса
и Google: адрес, телефоны, часы работы, ИНН, ОГРН, 10 регионов поставок.

**Перед вставкой поправить одну строку.** В файле дважды встречается
`"https://sssaturn.ru/logo.png"` — такого адреса на Tilda не будет. Сначала загрузить
`assets/logo/saturn-logo-color.png` в Настройки сайта → Файлы, скопировать выданную
ссылку и подставить её в оба места (`"logo"` и `"image"`). Иначе Яндекс не подтянет
логотип в карточку организации.

### 1.5. Ещё → предупреждение о cookie

- **Текст:** «Мы используем файлы cookie и Яндекс Метрику, чтобы сайт работал удобнее.
  Продолжая пользоваться сайтом, вы соглашаетесь с политикой обработки персональных данных.»
- Слова «политикой обработки персональных данных» — ссылка на `/privacy`
- **Кнопка:** «Хорошо»
- Показывать один раз, при первом визите, внизу экрана

Баннер обязателен, потому что подключается Метрика: она ставит cookie, а это
персональные данные по 152‑ФЗ. Ссылка заработает после шага 3 — если страницы
`/privacy` ещё нет, вернуться сюда и проверить, что ссылка не ведёт в никуда.

### 1.6. Аналитика → Яндекс Метрика

Вставить номер счётчика. Если счётчика ещё нет: metrika.yandex.ru → «Добавить счётчик»,
домен `sssaturn.ru`, включить **Вебвизор** и **карту скроллинга** — по ним потом видно,
где посетители бросают страницу.

Цели на отправку форм настраиваются позже, на шаге 10, когда формы уже существуют.

### 1.7. Соцсети

Загрузить `assets/web-launch/og-image.jpg` (1200×630) — картинка, которая показывается,
когда ссылку на сайт кидают в WhatsApp, Telegram или ВКонтакте. Без неё мессенджер
подставит случайный кусок страницы.

### Проверка шага

- [ ] Во вкладке браузера у сайта появился знак «Сатурна», а не серый круг Tilda
- [ ] В любом блоке в выборе цвета видна палитра проекта
- [ ] В выпадающем «Насыщенность заголовков» есть ExtraBold — значит 800 подгрузилось
- [ ] Открыть сайт → «Просмотр кода страницы» → найти `application/ld+json`, в нём
      ссылка на логотип ведёт на реальный файл Tilda, а не на `sssaturn.ru/logo.png`

## Шаг 3. Правовые страницы (30 минут)

Создать две страницы, текстовый блок, текст **дословно**:
- `/privacy` ← `legal/politika-obrabotki-pd.md`
- `/consent` ← `legal/soglasie-na-obrabotku-pd.md`

В обоих проставить дату публикации — ту, в которую сайт реально откроется.
Title и Description страниц — из `seo/meta-pages.csv`.

Сделать их первыми: на них ссылается галочка согласия во всех формах.

## Шаг 4. Формы (30 минут)

Настройки сайта → **Формы** → сервис **Email**, два адреса:
`nilov@sssaturn.ru` и `slobodina.marina@sssaturn.ru`.
Отправить тестовую заявку и убедиться, что письмо пришло **на оба**.

Состав любой формы на сайте:
- Имя (не обязательное)
- Телефон * (обязательное)
- Комментарий — только в попапе заявки
- **Чекбокс**, обязательный, по умолчанию снят:
  «Я даю [согласие на обработку персональных данных](/consent) и принимаю [политику обработки персональных данных](/privacy)»
- Сообщение после отправки: «Спасибо! Перезвоним в течение рабочего дня».

## Шаг 5. Каталог (1–2 часа)

1. Магазин → Товары → **Импорт CSV** → `catalogs/tilda-import-TEST-5.csv`
   (разделитель `;`, кодировка UTF‑8). Это **пробные 5 товаров**: удобрение, СЗР, семена,
   позиция без фото, позиция без цены.
2. Проверить на них: подтянулись ли фото по ссылкам, цена, характеристики,
   категории, переносы строк `<br>` в описании, и распознаёт ли фильтр по характеристике
   «Культура» несколько значений через запятую.
3. Всё сошлось → удалить пробные и импортировать `catalogs/tilda-import.csv` — 112 позиций.
   Не сошлось → написать мне, что именно, поправлю CSV.
4. Категории = разделы каталога; Гибриды/Сорта и Листовые подкормки — вложенные.
5. **Корзину и оплату выключить.** Кнопка в карточке — «Оставить заявку» (попап с формой из шага 4).
6. У 38 позиций без цены вместо цены — кнопка «Запросить цену» (тот же попап).

Фото тянутся из публичного репозитория `Saturnphoto`. **Его нельзя делать приватным** —
иначе картинки в каталоге пропадут.

## Шаг 6. Шапка и подвал (2 часа)

Настройки сайта → Ещё → страницы‑шаблоны **«Шапка»** и **«Подвал»**, чтобы правились в одном месте.

Zero Block, брейкпоинты: макет ПК 1440 → 1200, планшет 768 → 960 и 640, телефон 390 → 480 и 320.

Подвал по макету: контакты → навигация → «Реквизиты» → две кнопки «Скачать» → правовая строка.
Телефон и почту в подвале сделать высотой не меньше 44px (в макете 22 — мелко для пальца).

## Шаг 7. Главная, блок за блоком (1 день)

Каждый блок — отдельный Zero Block, сверху вниз:
герой → популярные позиции → семена → агросопровождение → результаты испытаний →
география → документы → контакты → нижняя панель (только 320–480).

Особенности — в таблице `TILDA-PLAN.md` §2. Важное:
- **Картинки** брать из репозитория, а не из макета: в публикации Claude Design 13 файлов
  не подгрузились (список в `TILDA-READY.md`), в репозитории они есть.
- **Блок «Результаты испытаний»:** строка «5 000+ га · 53 хозяйства · 89 опытных полей».
  Кнопок «Протокол ↓» нет, пока заказчик не даст обезличенные PDF.
- **Блок «Документы»:** три карточки, без серой подписи, номера свидетельств не дублировать.
- **Контакты на телефоне** — стандартный блок‑аккордеон, 6 человек.
- **География** — карта вставляется последней, её готовят отдельно.

## Шаг 9. Проверка перед публикацией (2 часа)

- [ ] Каждая страница на iPhone Safari, Android Chrome, планшете и ПК.
- [ ] Нажать все телефоны и почты — открывается звонилка и почта.
- [ ] Отправить каждую форму: без галочки не уходит, с галочкой письмо приходит на оба адреса.
- [ ] Все кнопки «Скачать» открывают правильный PDF.
- [ ] Поиск по каталогу, фильтр по культуре, переход по разделам.
- [ ] Несуществующий адрес открывает 404.
- [ ] Карточка товара: есть фото, цена или «Запросить цену», характеристики.
- [ ] PageSpeed и Яндекс Вебмастер → мобильность.

## Шаг 10. Публикация

1. **Снять заглушку** «Скоро здесь будет новый сайт» с адреса `/` и поставить туда
   новую главную (Настройки страницы → Адрес страницы). Заглушку не удалять —
   отложить в черновики, вдруг понадобится.
2. Опубликовать все страницы.
3. Яндекс Вебмастер: подтвердить сайт, отправить `sitemap.xml` (Tilda делает сама), регион — **Барнаул**.
4. Яндекс Метрика: цели на отправку каждой формы.
5. Проставить дату публикации в политике и согласии, если ещё не проставлена.
