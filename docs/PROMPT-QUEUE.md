# Накопитель правок для Claude Design

**Как работаем (решение 30.09.2026).** Правки не отправляются по одной. Заказчик
и я копим их здесь: она — когда смотрит макет, я — когда проверяю присланный
архив. Когда оба говорят «у меня всё», я собираю из накопителя один файл
`prompt-<дата>.md`, она отправляет его в Claude Design одним сообщением.
После отправки накопитель очищается, применённое переносится в «Отправлено».
