# Страница каталога — оформление блока ST340F

Все значения — из палитры проекта. Названия настроек взяты из интерфейса,
как их увидел агент при инвентаризации блока.

## Шапка блока

- Заголовок: `Каталог`
- Подзаголовок: **пустой**. Текст про 112 позиций убран 03.10.2026:
  он дублировал заголовок и отодвигал товары на экран вниз.
- Цвет заголовка `#141210`, подзаголовка `#8A837C`
- Шрифт — Montserrat (проектный, менять не нужно)

## Отступы и хлебные крошки

- Отступы блока: сверху 40, снизу 80 (было 135 и 135 — страница
  распадалась на пустые экраны). На телефоне 28 и 52.
- Хлебные крошки: вместо значка домика — текст `Главная`, размер 14.
  Домик 13px рядом с заголовком 44px смотрится случайным.
- Разделы: только на боковой панели. Плитки над товарами показывают
  пустые заглушки вместо картинок и занимают полтора экрана.
- Боковую панель не закреплять при прокрутке: из-за этого у неё
  появляется собственная полоса прокрутки.

## Список товаров

- Количество карточек в ряду: 4 на ПК, 3 на планшете, 2 на телефоне
- Промежуток между карточками: 20

- Выравнивание изображения: вписать, фон подложки `#F0EDE9`

## Страница товара

- Цвет заголовка `#141210`, цены `#141210`, характеристик `#141210`,
  названий характеристик `#8A837C`
- Кнопка в карточке — **«Оставить заявку»**, не «Купить». Если текст кнопки
  в настройках не меняется, сообщить об этом.
- Корзина и оплата должны быть выключены: сайт принимает заявки, а не заказы.

## Что проверить и сообщить

1. Есть ли настройка текста кнопки в карточке товара.
2. Можно ли отключить корзину и оформление заказа.
3. Что показывает карточка товара без цены — пусто или «Цена по запросу».
4. Есть ли поле для своего CSS у блока или у страницы.
