# Дубль «Состав» и «Действие» в карточках

Найдено 14.10 (карточка «Волски Оптим»): в характеристиках товара «Состав» и
«Действие» — один и тот же текст. Проблема системная, не разовая.

## Причина
В `catalogs/build_tilda_csv.py` одно исходное поле `Состав_ДВ` разливается сразу в
три характеристики Tilda:
- строка 110 → «Действующее вещество» ← `Состав_ДВ`
- строка 114 → «Действие» ← `Состав_ДВ`
- строка 117 → «Состав» ← `Состав_ДВ`

Отдельного поля «Действие» в `catalog_tech.json` нет, поэтому «Состав» = «Действие»
на каждой карточке, где заполнено `Состав_ДВ`.

Вдобавок у части позиций `Состав_ДВ` хранит НЕ состав, а описание действия
(напр. «Волски Оптим»: «Подкисляет рабочий раствор, связывает соли жёсткости…») —
то есть и ярлык поля неверный.

## Что сделать
1. Ввести в `catalog_tech.json` отдельное поле **`Действие`** (механизм/эффект).
2. Там, где `Состав_ДВ` сейчас описывает действие (11 позиций ниже) — перенести этот
   текст в `Действие`, а в `Состав_ДВ` занести **реальный состав** из каталога
   производителя.
3. Заполнить «Действие» и дополнить «Состав» из каталогов (в них информации достаточно):
   - `source-files/Katalog-Fertika-ProLine.pdf`
   - `source-files/Katalog-Genezis-NEW-2026.pdf` (Генезис в карточках упоминать можно)
   - `source-files/Katalog-Volski-Biokhim-skan.pdf`, `Buklet-Volski-Biokhim.pdf`
   - Реликт — каталоги Relict Organics
   - Официальные сайты: volskybiochem.com · fertika.com · relict-dv.ru
4. Поправить `build_tilda_csv.py`: «Состав» ← `Состав_ДВ`/`Состав`, «Действие» ← `Действие`
   (разные поля; если «Действие» пустое — строку не выводить, а не дублировать состав).
5. Перевыгрузить товары и обновить в Tilda.

**Только из прайса — цена. Состав/действие/нормы — из каталога производителя,
не выдумывать.** Описание не короче прайса, добавки — подтверждены каталогом.
