# Решения по проекту

## Платформа и инфраструктура
- Сайт делаем на **Tilda** (конструктор + хостинг в одном). Отдельный хостинг не нужен.
- Домен: **sssaturn.ru** (регистрируется/подтверждается у регистратора; A-запись → на Tilda; SSL выпускает Tilda бесплатно).
- Почта на домене (для формы): Яндекс 360 / VK WorkMail через MX-записи. Форма заявок → **nilov@sssaturn.ru**.
- Онлайн-оплаты нет — акцент на оптовую торговлю (заявка → КП → поставка).

## Структура сайта (прототип)
- Главная (лендинг-хаб): шапка → hero → направления (Удобрения/СЗР/Семена + услуги) → о компании → география → витрина каталога → бренды-дистрибьюторы → сертификаты и СГР → как заказать → «нам доверяют» → форма → подвал.
- Каталог — отдельная страница: фильтры (категория / производитель / культура / назначение) + карточки **без цен** («Запросить цену»).
- Карточка товара: галерея, «Цена по запросу» + запрос/КП, табы (описание / нормы применения / характеристики / документы).
- Новости/блог — **решено НЕ добавлять**.
- Дистрибьюторы: Реликт (relictorganics.com, relict-dv.ru), Фертика (fertika.com), Волский Биохим (volskybiochem.com).
- Референс по духу: targetagro.ru (корпоративный имиджевый — берём подачу: hero, крупные цифры, клиенты; каркас оставляем каталожный).

## Иконки
- **Монолинейный набор** (`assets/icons/saturn-icons.*`) — сохранён как рабочая система (направления, услуги, культуры), оранжевый.
- **Группа СЗР** (`saturn-icons-szr.*`): Защита + Гербицид/Фунгицид/Инсектицид/Протравитель (перечёркнутый круг = «против X»).
- **Стилевая эксплорация** (`saturn-icons-styles.*`): A плитка · B градиент-объём · C дуоцвет-контур · D бумажные слои.
- **Эмблемы** (`saturn-emblems-gradient.*`): эко-щиты в стиле B, оранжевый щит + зелёные листья.
- **Эко-щит** (`saturn-ecoshield.*`): точная реплика референса (серебро + зелёный).
- Итоговый стиль/цвет иконок — **на согласовании**.
