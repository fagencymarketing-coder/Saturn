# Дизайн-видение сайта «Сатурн»

Камертон работы. Дополняет `brand/` (логобук — источник правды по токенам) и
`docs/HANDOFF.md` (контекст/данные). Роль: senior full-cycle (Claude Code —
вёрстка, Claude Design — макеты, Tilda — сборка).

## Главная эстетическая идея — тихая дороговизна
Премиальность из сдержанности, не из эффектов: воздух вокруг элементов,
выверенная типографика, единственный акцент скупо и метко, настоящие фото в
едином тёплом свете, безупречная согласованность. «Дешёвый кричит — дорогой
уверенно молчит». При сомнении «добавить/убрать» — чаще «убрать». Пустое
пространство берегём.

Тон для аудитории (агроном, снабженец, руководитель хозяйства): надёжный
партнёр — по-деловому, ясно, с достоинством. Не развлекать — внушать уверенность.

## Как работаем
- Есть утверждённый макет всей главной целиком — карта и камертон ритма.
  Дорабатываем **по одной секции**, держа целое; финал собираем в Tilda.
- Единство держится на трёх опорах: общие **токены**, общий **эталон**
  (герой + полный макет), общее **дыхание** (ровный вертикальный ритм секций).
- Порядок: сначала чиним сломанное/неверное (обрезанный текст, чужие данные),
  потом усиливаем. Усиление = сила иерархии и ясность, тем же набором, точнее.
- Формат выдачи по секции: промт для Claude Design + код/инструкция для Tilda
  с понятным «куда вставить».

## Язык дизайна (ориентиры, калибруются под макет)
- **Цвет:** оранжевый `#FF4200` — голос бренда, звучит тем сильнее, чем реже;
  ведёт к главному действию. Один акцент на экран. Текст — `#1A1A1A`; нейтрали
  `#6B6560` / `#F6F5F3` / `#E7E3DE`; белый — воздух. Мелкий текст тёмный,
  оранжевый — для крупного и действий (контраст).
- **Шрифт:** Montserrat, одна семья. H1 ~56 (моб.36) / H2 ~40 (моб.28) /
  H3 ~28 / Lead ~20 вторичным / Body ~17 lh1.6. Строка ~60–65 знаков.
- **Ритм:** сетка 8pt (8/16/24/32/48/64/96). Между секциями 64–96 (десктоп).
  Контейнер ~1200.
- **Форма:** округлость как ДНК (поля/кнопки ~12, карточки ~20, теги-капсулы),
  мотив полукругов — в футере и акцентных плашках. Космос (планеты/орбиты) в
  герой НЕ тянем — круги читаем как фирменную геометрию.
- **Иконки:** Phosphor, начертание **Fill**, одноцветные через `currentColor`
  (в `assets/icons-new/`). Единство набора важнее отдельной иконки.
- **Фото:** настоящие, тёплые, крупные (продукция, поля, склад, люди), единый
  грейдинг.
- **Движение:** тонкое и быстрое (мягкий hover, лёгкое проявление при скролле).

## Эталон героя
Светлый сплит текст+фото, тёмная шапка; заголовок с одним оранжевым
акцент-словом; спокойный подзаголовок; ведущая кнопка «Подобрать решение» +
мягкая вторичная «Перейти в каталог»; строка доверия крупными цифрами; тёплое
фото продукта. Тёплая полевая эстетика — в блоке «О компании».
(Отличие от прежнего прототипа V4.4, где герой был тёмным: актуален светлый
сплит-эталон.)

## Структура главной (11 блоков)
Хедер → Герой → «Пять направлений — один поставщик» + партнёры → «Популярные
позиции» (карточки + фильтр) → «Сервис» (4 шага + диагностика/агросопровождение)
→ «О компании» (светлый, фото поля) → «География поставок» (8 регионов + карта)
→ «Результаты испытаний» → «Документы и сертификаты» → «Свяжитесь со
специалистом» (контакты + форма) → тёмный подвал.

Меню: **Каталог · Агросопровождение · О компании · Контакты**.
Пять направлений: Удобрения, СЗР, Семена, Диагностика, Агросопровождение.
Каталог — отдельная страница (Tilda «Каталог-товары»); «Перейти в каталог» /
«Весь каталог» и карточки направлений ведут туда (с фильтром по направлению).

## Порядок цикла/процесса (ВАЖНО, единый по сайту)
**Диагностика → Подбор препаратов → Поставка → Сопровождение применения.**
Диагностика идёт ПЕРВОЙ (сначала обследуем поле, потом подбираем). Эталонная
формулировка — подзаголовок блока направлений (использовать дословно):
«Полный цикл — от диагностики поля до подбора препаратов, поставки и
сопровождения применения.» Прежний порядок «Подбор → Диагностика →…» неверен —
везде исправлять.

## Выразительность + единство (ритм свет/тёмное)
Сайт делаем выразительным через КОНТРАСТ и РИТМ, не через «больше оранжевого».
Ритм полос: светлые секции, пунктуированные 2–3 тёмными (Ink Black) —
signature-полосы. Предварительно: Герой (свет) → **Направления (тёмная)** →
Каталог (тёплый свет) → Сервис (свет) → О компании (свет, фото) →
**География (тёмная)** → Результаты (свет) → Документы (свет) →
**Контакты (тёмная)** → Футер (тёмный + паттерн).

Связующая ткань (делает блоки единым целым — соблюдать в каждой секции):
1. Один набор токенов везде (#FF4200, Montserrat, 8pt, радиусы); тёмные секции —
   зеркальные токены, не «другой дизайн».
2. **Минимализм по умолчанию, карточки — скупо.** Иконки БЕЗ подложек-кружков
   (не превращаем в карточки); направления/преимущества — открыто: иконка +
   подпись, разделённые воздухом или тонкой линией. Контейнеры-карточки только
   там, где нужна группировка (форма, карточки товара в каталоге). Когда карточка
   всё же нужна — единый язык: радиус 20, общий паддинг, границы светлая
   `#E7E3DE` / тёмная `rgba(255,255,255,.08)`.
3. Одинаковое начало секций: лейбл → H2 → подзаголовок/бейдж; ритм 64–96;
   контейнер ~1200.
4. Мотив полукругов тихо повторяется в тёмных секциях и футере.
5. Единый тёплый грейдинг всех фото.
6. Дисциплина акцента: оранжевый в каждом блоке работает одинаково (одно
   действие / один акцент).
7. Тёмных полос немного (2–3), равномерно; стыки — чистый край во всю ширину +
   щедрый паддинг.

Уточнения (по ходу правок):
- **Никаких лишних подложек**, в т.ч. у бейджей-подзаголовков: иконка + текст без
  капсулы/коробки.
- **Паттерн полукругов — осторожно**: не должен читаться как орбиты/мишень
  (космос). Если сомнение — не добавлять.
- **Логотипы партнёров — только в фирменных цветах** (чужие бренды, не
  перекрашивать, не делать моно). Единство ряда — через одинаковые белые капсулы
  (равная высота/паддинг/радиус), равный оптический размер логотипов и одинаковый
  воздух между ними.

## Блок «Полный цикл» — структура «цикл как путь» (УТВЕРЖДЕНА, 2026-09)
Тёмный signature-блок показывает цикл, а не перечисляет иконки:
- H2 (акцент «Полный цикл» оранжевым; допускается оранжевая цифра «до +45%» в
  герое — решение дизайнера). Строки-подзаголовка НЕТ (убрана 2026-09 —
  дублировала шаги).
- **4 шага цикла** слева направо в 4 равных колонках, соединённые тонкой линией
  (1px `#FF4200` op .35) через 4 узла-точки (6px, `#FF4200`), линия от узла 01
  до узла 04 (не до краёв). В каждой колонке: цифра-призрак фоновым слоем
  (01–04, ~96px/800, `rgba(255,255,255,.06)`) → иконка Phosphor 32px оранжевая
  над линией → узел → заголовок шага (белый 17/700) → строка сути
  (13px `rgba(255,255,255,.55)`).
  Шаги: 01 Диагностика («собственная лаборатория»), 02 Подбор препаратов
  («под культуру и задачи»), 03 Поставка («логистика и хранение включены»),
  04 Сопровождение («агроном весь сезон»).
- Капсул-чипов направлений под шагами НЕТ (убраны 2026-09 — дублировали шаги
  и фильтры каталога в следующем блоке). Состав блока: H2 → 4 шага → партнёры.
- Мягкое радиальное свечение `rgba(255,66,0,.07)` справа-сверху. Партнёры-
  производители внизу (белые капсулы, фирменные цвета).
- Hover шагов/иконок: scale(1.08) + свечение drop-shadow оранжевое + подъём
  (оба эффекта одновременно). На мобиле шаги в столбик, линия вертикальная.

## Эталон тёмной секции (УТВЕРЖДЁН на блоке «Пять направлений»)
Ориентир для всех тёмных секций (География, Контакты):
- Фон ровный тёмный `#0E0D0C`, без паттерна/кругов/орбит.
- H2 белый (акцент-слово оранжевым — по желанию, не обязательно).
- Подзаголовок — просто текст (светло-серый), БЕЗ бейджа/подложки/иконки.
- Контент открыто, без карточек и без подложек под иконками: оранжевые иконки +
  белые подписи, разделённые тонкими вертикальными линиями `rgba(255,255,255,.1)`.
- Один акцент — оранжевые иконки.
- Логотипы партнёров — в отдельных белых капсулах, в фирменных цветах (не
  перекрашивать), равного размера и воздуха.

## Приоритеты правок по текущему макету
1. Оранжевый не должен звучать слишком часто (особенно в ряду карточек товаров).
2. Данные везде настоящие и согласованные (контакты/цифры — по HANDOFF).
3. Самый плотный блок («Сервис») — дать больше воздуха.
Частые огрехи генератора: подзаголовки в несколько цветов; вымышленные
контакты; перепутанные иконки направлений — спокойно выверять.

## Tilda — технический горизонт
Стандартные блоки для типового, Zero Block для авторского, HTML-вставки для
особенного. Глобальные цвета/шрифты — один раз. SVG вставлять кодом (перекраска
через currentColor). Изображения лёгкие (WebP, lazy load). Адаптив сразу
(как сетки складываются на телефон). SEO (мета, alt, семантика), подключение форм.
