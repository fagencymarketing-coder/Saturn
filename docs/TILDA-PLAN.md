Макеты: 7 архивов Claude Design от 30.09.2026 (главная, каталог, карточки, политика,
согласие — ПК 1440, планшет 768, телефон 390). Домен sssaturn.ru уже подключён к
проекту Tilda (см. `DOMAIN-DNS.md`).

## 0. До начала
- [ ] Шрифт: Настройки сайта → Шрифты → Montserrat (Google Fonts), начертания 400, 500, 600, 700, 800.
- [ ] Цвета проекта: `#FF4200` акцент, `#141210` тёмный, `#F6F5F3` светлые секции, `#F0EDE9` плитки, `#8A837C` подписи.
- [ ] Favicon — знак «Сатурна» (`assets/logo/`).
- [ ] Язык сайта — русский; заголовок и описание страниц — из `seo/meta-pages.csv`.

## 3. Каталог (Tilda Store)
1. Магазин → Товары → **Импорт CSV**: файл `catalogs/tilda-import.csv` (разделитель `;`, UTF-8).
   Фото подтянутся по ссылкам из репозитория `Saturnphoto` — он должен оставаться публичным.
2. **Сначала пробный импорт 5 товаров** (1 удобрение, 1 СЗР, 1 семена, 1 без фото, 1 без цены) —
   проверить: фото, цена, характеристики, категории, разрывы строк `<br>` в описании.
3. Категории = разделы каталога (Семена, Гербициды, …). Подразделы (Гибриды/Сорта, Удобрения/Листовые подкормки) — вложенные категории.
4. Фильтр по культурам — фильтр Store по характеристике «Культура». Проверить на пробном импорте,
   что значения через запятую распознаются как несколько культур; если нет — культуры завести метками/категориями.
5. Товары без цены (38 шт.): в Store цена пустая → вместо цены кнопка «Запросить цену» (попап).
6. Карточка товара: поля — Состав / Действующее вещество, Норма расхода, Культуры и фазы, Фасовка,
   Физико-химические показатели; у семян — Спелость, Вегетационный период, Урожайность, Качество, Оригинатор.
7. Корзину и оплату **выключить**: сайт принимает заявки, а не заказы. Кнопка в карточке — «Оставить заявку» (попап с формой).
8. Прайс PDF: `catalogs/Прайс-лист-Сатурн-2026.pdf` — загрузить в Tilda (Настройки → Файлы) и поставить ссылку на все кнопки «Скачать прайс».

## 4. Формы и 152-ФЗ
- Все формы (контакты, попап заявки, «Не нашли нужное?», карточка товара): поля Имя, Телефон*, Комментарий (только в попапе).
- **Галочка согласия** — поле «Чекбокс», обязательное, по умолчанию не отмечено, текст:
  «Я даю [согласие на обработку персональных данных](/consent) и принимаю [политику обработки персональных данных](/privacy)».
- Куда приходят заявки: Настройки сайта → Формы → почта + (опц.) Telegram/CRM. **Адрес уточнить** (см. «Чего не хватает»).
- Сообщение после отправки: «Спасибо! Перезвоним в течение рабочего дня».
- Cookie: Настройки сайта → Ещё → «Предупреждение о cookie», текст из `legal/cookie-banner.md`.

## 5. SEO и аналитика
- Микроразметка: `seo/jsonld-site.html` — в «HEAD» всего сайта; `seo/jsonld-breadcrumbs-catalog.html` — на `/catalog`.
- Мета-теги страниц и товаров — `seo/meta-pages.csv`, `seo/meta-products.csv`.
- Яндекс Метрика: Настройки → Аналитика → номер счётчика; цели на отправку форм.
- Яндекс Вебмастер: подтвердить сайт, отправить `sitemap.xml` (Tilda делает сама), регион — Барнаул.
- Картинка для соцсетей (OG) — Настройки страницы → Соцсети.
