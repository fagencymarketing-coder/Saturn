адъюванты, их снимков нет ни у нас, ни в каталогах партнёров.

только те, у кого есть фото** (колонка `На_главной` в `catalog_tech.csv`).

## design/geo-map/ — карта
`saturn-map-geo.png` — готовый рендер. `build_map.py` — генератор по реальным
границам регионов, `regions.geojson` — границы 83 субъектов.
Пины считаются как центроиды полигонов, поэтому всегда внутри своего региона.
