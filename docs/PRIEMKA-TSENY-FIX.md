## Что произошло

линейки Волски**. До импорта магазин стоял с ВЕРНЫМИ ценами (проверено снимком API),
импорт их **перезаписал на старые**. Источник истины — прайс
`source-files/Saturn-katalog-i-prays-2026-10-13.xlsx` (лист «Каталог», колонка цены).

Пример: Страда N на главной (захардкожена) 409,5 — верно; в каталоге и на карточке
315 — из сломанного импорта.

## Что сделать (данные + импорт Дарьи)
1. Найти, почему в `tilda-import.csv` у линейки Волски цены разъехались с прайсом
   (скрипт выгрузки берёт цену не из `Цена_итог` прайса 13.10 / старый источник).
   Пересобрать CSV так, чтобы **Price = прайс 1:1** по ВСЕМ позициям, не только 18.
2. Из CSV убрать **«Волски Аминатор»** (решение Р1 — его нет в прайсе).
3. Дарья переимпортирует исправленный CSV (обновление по SKU, «Заменить имеющиеся
   изображения» для фото, см. п.32 в SDACHA.md).
4. После импорта — повторная программная сверка всех цен сайта с прайсом = **0
   расхождений**, и проверка, что «Волски Аминатор» исчез (каталог = 86).
