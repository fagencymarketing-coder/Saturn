# ТЗ чату ребрендинга sssaturn.ru

Отдельный чат, который переписывает все тексты сайта под новое позиционирование.
Создан 31.10.2026 после встречи с заказчиком 27.10.

## Зона ответственности

| Кому | Что правит |
|---|---|
| **Чат ребрендинга (этот)** | Только `docs/TEKSTY-*.md` — тексты и ТЗ по блокам |
| Чат вёрстки | `design/blocks/*.html`, HEAD, `tools/build_head_code.py` |
| Чат данных | `catalogs/`, `tilda-import.csv`, репозиторий Saturnphoto, прайс, СГР |
| Агент Tilda | Вставка кода в Tilda и публикация |

**Правило проекта: один файл правит один чат.** Чат ребрендинга **не трогает**
`design/blocks/`, HEAD, каталоги и фото — иначе правки затирают друг друга.
Тексты отдаёт файлами, вёрстку делает другой чат.

## Что нужно сделать

1. **Изучить сайт** — пройти главную и внутренние страницы, выписать все тексты,
   которые противоречат новому позиционированию.
2. **Переписать тексты всех восьми блоков** по новому позиционированию.
   База уже есть в `POZICIONIROVANIE-2026-10.md` — развить её, а не начинать с нуля.
3. **Написать текст отдельной страницы «О компании»** — расширить черновик.
4. **Пройти сайт по списку запрещённых формулировок** и дать замену каждой:
   «Каталог» → «Продукция», «Агросопровождение» → «Агроскаутинг», «Реликт ДВ» —
   убрать, канцелярит — заменить фактом.
5. **Тексты карточек товара** — шаблон подписей и микротекстов для новой карточки
   (макет делает чат вёрстки).
6. **Собрать открытые вопросы** к заказчику одним списком.

## Как отдавать результат

Отдельные файлы в `docs/`, по одному на блок или по одному на страницу:
`TEKSTY-01-GLAVNYY-EKRAN.md`, `TEKSTY-02-EKSPERTIZA.md` и так далее.
Внутри — только текст, который пойдёт на сайт, без вёрстки и без HTML.
Для каждого фрагмента помечать: заголовок, надзаголовок, лид, кнопка, подпись.

Коммитить в свою рабочую ветку и называть её в ответе. В `main` напрямую
не пушить — вливает чат вёрстки.

## Правила текста

- Не заявляем качества («надёжный», «профессиональный»,
  «высококвалифицированный») — показываем действие и число.
- Прилагательное заменяем фактом.
- Ценность — в рублях на гектар, а не только в процентах.
- Ничего не выдумываем. Любая цифра должна подтверждаться актом, прайсом
  или документом из репозитория. Нет подтверждения — в список вопросов.
- На главной лаконично: подробности раскрытием списка или на отдельной странице.

## Чего нельзя

- Менять что-либо на живом сайте. Все правки согласует заказчица.
- Приписывать «Сатурну» активы производителя (см. открытый вопрос 1
  в `POZICIONIROVANIE-2026-10.md`).
- Упоминать ГК «Реликт ДВ» в любом виде.
- Обещать блог и рассылки — их нет.
