## Порядок работ

1. **Заказчица отвечает на раздел 3 (Р1–Р7)** — без этого часть правок вслепую.
2. **Чат вёрстки** → один промт агенту (`design/handoff/AGENT-DOBOR-2.md`), агент
   вставляет HEAD + блоки и публикует. Это снимает большинство 🟡.
3. **Чат данных** правит цены, единицы, подписи, справочники; выгрузка товаров.
4. **Дарья** в Тильде: раздел «СЗР», заголовки магазина, og:title, Метрика, почта,
   и — последним — корень домена на Главную.
5. **Повторная приёмка** по `design/handoff/AGENT-PRIEMKA.md` — только после публикации.

**Критерий сдачи:** всё 🟡 опубликовано; данные закрыты; повторная приёмка — ноль
расхождений; корень домена переключён на Главную.
