### Структура репозитория (github.com/fagencymarketing-coder/-)
```
prototype/

  render_v44.cjs            — Playwright: скриншоты + PDF
  build-assets/             — logo_datauri.txt, logo_color.txt, icons.json (base64)
  Saturn-prototype-v44.pdf

research/                   — src-*.txt (справка/КП/письмо), competitors, final-brief,
                              references (БЕЗ переписки chat.* — там был пароль reg.ru)
```

### Как пересобрать прототип (в новой сессии — работает «из коробки»)
```
cd prototype
python3 build_v44.py       # генерит site-prototype-v44.html (ассеты берёт из build-assets/)
node render_v44.cjs        # v44-desk.png / v44-mob.png + Saturn-prototype-v44.pdf
```
Node: `/opt/node22/bin/node`; Playwright chromium в `/opt/pw-browsers`
(render_v44.cjs уже указывает нужные пути). Сборка НЕ зависит от /tmp —
все ассеты в `prototype/build-assets/`.

### Как вносить правку
1. Открыть `prototype/build_v44.py`, найти нужный блок (они помечены
   `<!-- N. НАЗВАНИЕ -->`), отредактировать текст/структуру.
2. `python3 build_v44.py && node render_v44.cjs` из `prototype/`.
3. Проверить `v44-desk.png` / `v44-mob.png`; убедиться, что нет
   горизонтального скролла (скрипт печатает `overflow=false`).
4. Закоммитить.
