### Шесть телефонов в блоке контактов

На живой «Главной» в блоке контактов видны **шесть** номеров на обеих
ширинах:

| Номер | |
|---|---|
| +7 (960) 953-48-88 | Алексей Нилов |
| +7 (913) 022-48-88 | |
| +7 (963) 502-38-55 | |
| +7 (960) 948-83-40 | |
| +7 (903) 947-73-53 | |
| +7 (983) 170-01-70 | |

В таблице каталога, лист «Статус», записано обратное: «На сайте
показываем только Алексея Нилова +7 (960) 953-48-88 — решение
заказчика». Либо решение с тех пор поменялось, либо пять чужих
мобильных опубликованы по недосмотру. Сам не трогаю: это живые люди,
и убрать номер — решение заказчика, а не вёрстка.

### Баннер cookie

На телефоне занимает 277px — треть экрана — и перекрывает обе кнопки
героя на первом экране. «Принять все» в `#FF4200` — самая яркая кнопка
на экране, ярче главного призыва. Правка готова мысленно, но меняет
вид: нужно «да».
