# Анализ конкурентов (из PDF Perplexity) — выводы для «Сатурн»

## Главный вывод
Модель сайта = НЕ обычный интернет-магазин и НЕ имиджевый лендинг, а
**B2B-каталог с быстрым подбором решения агрономом**. Собрать гибрид из сильных моделей.

## Топ-референсы и что перенести
- **ДМ Агро** — порядок блоков главной + сценарий заявки: первый экран с конкретным результатом, 2 CTA («Получить консультацию» + «Подобрать решение»), популярные товары на главной, контакт конкретного агронома/менеджера, форма (регион, культура, площадь, задача, телефон).
- **БДА Капитал** — визуал: крупные фото полей, карточки культур, быстрый вход «по культуре», глагольные CTA («подобрать/выбрать» вместо «Подробнее»), компактная форма, блок «работаем с ведущими производителями».
- **Bayer Crop Science** — мастер подбора «культура → проблема → решение», поиск по товару И по вредному объекту, справочник болезней/вредителей/сорняков.
- **Агросорос** — эталон большого каталога: мегаменю (пестициды/удобрения/спецпродукты + культуры), ДВА пути «по типу продукта» и «по культуре», фильтры зависят от категории, страницы производителей, карточки полевых опытов.
- **ФЭС-Агро** — корпоративное доверие: цифры, география, партнёры.
- Сингента / Татагрохимсервис / UPL — экспертный контент, отраслевые фото, карточки препаратов (ДВ, применимость).

## Что НЕ делать (из анализа)
- Пустой «корпоративный голос» без связи с регионом/реальной компанией.
- Необоснованные «№1», «лучшие цены», «гарантия урожая».
- Форма из 8–10 обязательных полей до первого контакта.
- Дубли кнопок «Подробнее» без понятного результата.
- Автомагазин с корзиной (опт всё равно через уточнение цены/объёма/доставки).

## Ключевые идеи для нашей структуры
1. Два входа в каталог: **по типу продукта** и **по культуре**.
2. **Глагольные CTA**: «Подобрать решение», «Получить консультацию» (не «Подробнее»).
3. **Форма подбора**: регион + культура + площадь + задача + телефон (заявка сразу полезная).
4. **Региональные специалисты** (конкретный агроном/менеджер), не безличный отдел.
5. **Полевые опыты/кейсы** как доказательство (у нас есть кейс СибАгро).
6. Фильтры **зависят от категории** (СЗР: вид + культура + вредный объект; семена: культура, сорт/гибрид).
7. (Фаза 2) Мастер «культура → проблема → решение» + справочник вредных объектов.

## Визуальный отчёт v2.0 (со скриншотами) — детали

### Рекомендуемая главная (10 блоков)
1. Первый экран — результат для хозяйства + регион + CTA «Подобрать решение» / «Каталог» (ДМ Агро, БДА)
2. Быстрый подбор — культура, регион, площадь, проблема/задача (Bayer, БДА)
3. Категории — Семена, СЗР, Удобрения, Агросопровождение (Сингента, Агросорос)
4. По культуре — карточки культур → решения (БДА, Bayer)
5. Популярные решения — 6-8 карточек + «запрос цены» (Агросорос, UPL)
6. Почему «Сатурн» — факты, цифры, оригинальность, логистика (ФЭС-Агро)
7. Как работаем — заявка → расчёт → предложение → поставка → сопровождение (ДМ Агро)
8. Производители — логотипы/страницы брендов (Агросорос)
9. Агросопровождение — этапы, результат, CTA «выезд агронома» (Татагрохимсервис)
10. Кейсы и знания — региональные результаты, сезонные статьи (Сингента)

### Фильтры каталога (по разделам)
- СЗР: культура, тип препарата, вредный объект, ДВ, производитель, форма, фасовка.
- Семена: культура, производитель, спелость/ФАО, технология, устойчивость, регион допуска.
- Удобрения: способ внесения, культура, фаза, состав, форма, назначение, упаковка.

### Карточка товара
Название/категория/производитель/реальное фото · назначение · культуры и вредные объекты ·
ДВ/состав/концентрация/форма/фасовка · нормы и регламент · документы (инструкция, декларация,
сертификат, паспорт безопасности) · наличие/«под заказ» · CTA «Запросить оптовую цену» +
«Консультация агронома» · связанные препараты/схемы. Без корзины (опт).

### Дизайн-направление (важно — отличается от нашего тёмного!)
- Светлая основа, много воздуха. Тёмно-зелёный или графит как основной, ОДИН яркий акцент CTA (лайм/жёлтый/тёплый оранжевый).
- Крупная современная типографика без «фермерской» стилизации.
- Реальные фото полей/культур/специалистов/складов; упаковка — только реальная.
- Чёткая сетка карточек, минимум теней/иконок; короткие анимации.
- НЕ использовать: сток «рука с колосом», разнобой зелёных, баннеры производителей, «№1/лучшие цены», формы 8-10 полей.

### 3 макета для проектирования: БДА (композиция) · Bayer (логика выбора) · ДМ Агро (порядок главной). Агросорос — если каталог большой.
