3. ГАЛОЧКА СОГЛАСИЯ — В ОДНУ СТРОКУ С ТЕКСТОМ
═══════════════════════════════════════════════
Во всех формах сайта (контакты, попап заявки, «Не нашли нужное?», карточка товара)
чекбокс сейчас стоит на отдельной строке НАД текстом. Должно быть: квадрат 18×18
слева, отступ 10, текст справа отдельной колонкой. Выравнивание по верху
(align-items: flex-start), перенос строк текста не должен уводить его под чекбокс.
Вся строка — одна цель нажатия высотой не меньше 44.
