# СТАТУС ПРОЕКТА «Сатурн» (обновлено 10.09.2026)

## О проекте
- ООО «Сатурн» (Барнаул), опт: удобрения, СЗР, семена для АПК. Домен sssaturn.ru, платформа Tilda.
- Дилер: Фертика, Реликт (Генезис/Реликт ДВ), Волский Биохим; СЗР — «Рувенст» (уточнить).
- ЦА: агрономы/закупщики. Цель — заявка. Цен на сайте нет («Запросить цену»).
- Бренд: оранжевый #EE4A0E + зелёный #1F9E57; шрифты Archivo + IBM Plex.

## Сделано
- Заглушка (тёмная, волна) — утверждена, контакты вписаны, адаптив, версия под T123. Нет Telegram-ссылки.
- Прототип — утверждён V2 (Hero→Цифры→Каталог удобрения/защита→Семена→Карточка→Сертификаты→Доверие→Форма→Подвал). Есть PDF. V3 отклонён.
- Домен sssaturn.ru: отвязан от хостинга reg.ru, A @/www → 176.57.66.96, SSL выпущен, HTTPS работает. (Ошибка ERR_TUNNEL у клиента = локальный VPN.)
- Каталог: Saturn-catalog.xlsx — 84 позиции (удобрения 43, СЗР 32, адъюванты 9), OCR прайса 2026 + сверка.
- Материалы заказчика разобраны в catalogs/ (прайс OCR, каталоги, справка, КП, реквизиты).

## Ждём от заказчика
- Бренд СЗР («Рувенст»?) + 5–6 нечитаемых цен/составов.
- Telegram-ссылку для заглушки.
- Фото товаров, реквизиты (ИНН 2801274078 / ОГРН 1232800002709 — есть), логотипы клиентов, сертификаты/СГР.
